# 视觉方案提案：多视图约束的局部坛颈形状估计

日期：2026-10-21。状态：针对用户“具体方案是什么”的讨论提案，未共同定案，本轮未运行新实验。
工况以[研究方向](research_direction.md)为准：固定摆放，每坛一次识别，个体形状不同，
弱结构边界、有限视角和深度偏差均需处理。目标仍是实际扎带截面，不能用口沿圆代替。

## 1. 主线与关键假设

建议先估计口唇下方至坛肩之间的一段局部形状，再在其中寻找扎带截面。
不要求目标截面已经是一条清晰图像边，不固定坛高、颈位、直径或竖直法向，也不重建整个坛体。

起始局部模型采用**方向可变的颈轴与随轴向变化的半径曲线**：

```text
p(s,theta) = c0 + s*n + r(s)*(u*cos(theta) + v*sin(theta))
```

`n`为局部颈轴，`u,v`在其法平面内；`r(s)`用平滑曲线表示而非固定CAD。
每只坛分别求`c0,n,r(s)`，颈轴独立于坛身轴。首个模型允许直颈局部倾斜，
不声称覆盖真正弯曲的颈轴或任意不圆；这些形状应显式验证模型失配，不能强制拟合后报成功。

**需要首先验证的假设**是目标附近截面可用近似圆表达，而且足够槽形信息在侧视轮廓/有效深度中可见。
旋转曲面轮廓重建有既有理论依据，但其形状假设、单视图尺度/姿态歧义不能省略。
参考[Wong、Mendonça、Cipolla原文](https://i.cs.hku.hk/~kykwong/publications/kykwong_ivc2004.pdf)。
把该思想用于歪颈局部、已标定多视图和有偏深度是本项目候选设计，不是已验证的论文复现或创新结论。

## 2. 候选观测配置

- 最小多视图候选为两台固定侧视RealSense，朝向具有明显夹角，优先让口唇下颈区可见。
- 第三台作为增量对照；是否加入、侧视还是俯视取决于额外提供的信息，而非沿用历史阵列。
- 同一识别窗口获得各路RGB与深度，不依赖转坛、移动相机或返回重拍。
- 均匀照明与清楚背景用于稳定轮廓，先用简单前景分离，不将大模型设为必要依赖。
- 米制内外参独立标定并固定；相机同步的实际RGB/深度曝光关系将来须单独核实，
  深度支持硬同步不能直接当成多路RGB已经同步。当前不连接或重新标定设备。

多机技术边界参考[RealSense官方配置说明](https://dev.realsenseai.com/docs/multiple-depth-cameras-configuration/)。

## 3. 每坛一次识别的算法流程

1. **找局部颈区。** 利用整坛掩码与上部轮廓产生口唇—颈部—坛肩候选区。
   ROI随实际图像而变，不用固定像素框、固定颈高或目标真值；歪颈保留多个候选方向。
2. **提取可解释证据。** RGB给左右外轮廓及可见局部边缘，深度给槽区有效表面点。
   不把不同相机的轮廓点直接当同一个三维点三角化，也不把椭圆中心当真实圆心投影。
3. **估计局部形状。** 将同一候选曲面投影到各相机，与各自真实轮廓比较，同时计算有效深度点的表面残差。
   RGB与深度分别归一化、加权和鲁棒处理；保存两者各自残差，不只输出混合总分。
4. **从剖面选截面。** 在口唇下的局部工艺范围内查找`r(s)`的谷值/较窄区间，
   输出候选中心、法向、半径及邻近槽宽，不在全坛范围寻找全局最小半径。
   平缓槽底或多个接近候选时保留区间/多解，必要时拒绝唯一圆；工艺所需带宽尚未给定。
5. **质量判断。** 检查模型是否解释各视图、RGB和深度是否冲突、截面位置是否稳定以及模型是否明显不圆/不共面。
   输出接受或拒绝及原因；低残差不能排除共同标定偏差，绝对精度仍需独立基准。

## 4. 深度偏差如何进入方案

主张让已标定多视图RGB提供与深度不同来源的几何约束，而不是先将深度点云当真值。
这是减小依赖深度的候选路线，**不是RGB能消除任何深度偏差的承诺**。

- 先分别求RGB几何结果与RGB-D局部几何结果，观察偏差传到哪些参数，作为可解释基线。
- 联合模型对深度使用软约束，RGB/深度明显冲突时降权或拒绝，不通过放宽门限硬输出。
- 相机内外参和深度尺度/偏置不得与未知坛形一起无限制放开优化，避免相互补偿出低残差错误解。
- 未来实机阶段用独立参考件量化每机偏差后，才决定偏差修正模型与权重；本阶段仅讨论和设计仿真扫描。
- 相机标定误差、模型失配和深度偏差可能产生相似现象，单只未知酒坛不保证能区分它们。

若槽区不出现在任何有用轮廓中，RGB对该处只能提供间接先验；此时需要足够可靠的深度或修改观测配置。
多视图轮廓不是任意未见凹面的完整重建证据。

## 5. 分阶段验证与当前停点

仿真前先核对[最小几何与观测模型草案](minimal_model.md)：参数规范、候选截面定义、
轮廓切触关系、深度含义及平缓槽底的敏感度。无需等待完整理论证明，但不能省略这些定义。

**下一阶段建议只验证局部模型与观测是否足以确定截面，不同时铺开全部噪声和完整流水线。**
使用准确相机参数与理想可见掩码诊断，覆盖直颈、局部倾斜颈、浅而平缓槽、明显非圆或弯颈的反例、
口唇遮住槽区的情形；摆放固定。比较单RGB-D、两视图RGB局部模型及第三视图的增量。
明确哪些诊断输入来自真值；先不用真值初始化制造结果，也不把该阶段称为自然RGB提取通过。

关键失败证据是：是否存在不同目标截面几何能同样解释可用轮廓，或理想输入下目标误差仍超出
4mm要求。若有，先补约束/改模型/改布局，不能寄望更好的分割解决观测不足。

理想诊断通过后，下一阶段才检验实际图像提取与弱边界；随后单独分析有偏深度，比较
深度基线、RGB基线和联合模型。接受、拒绝、错误接受及耗时均保留，最终实机独立验收另行安排。

本文件只给出可讨论的主线、假设和首个验证问题，不启动实验。既有探索代码不等于已实现本方案。
