# 扎带窄槽目标截面的误差预算与独立验收

日期：2026-10-21。状态：离线研究设计与证据边界；没有操作实机。本文件把误差机制、公式、参数依据与待做实验列成可执行合同，结果以实际批次报告为准，不把假设范围写成设备实测性能。方法来源见 [方法调研](method_review.md)，历史结构证据见 [历史几何核查](historical_geometry.md)。

## 1. 被测量与验收量

用户已确认目标为凸起口沿下方实际扎带窄槽截面。仿真暂定义 `binding_band_section` 为窄槽范围内半径最小位置处的圆，输出中心 `c`、单位法向 `n`、半径 `r`、质量/不确定性和拒绝原因。真实工艺截面还需按扎带接触位置、槽底可用宽度及量具可测基准确定。平槽底可能不止一个最小值，真实不圆、不共面也可能没有唯一“精确圆”；这时应保留实际截面点及最佳圆残差，不能只输出一个看似确定的圆。

法向按已定义的坛轴正向/世界向上定向；同一批不得一部分使用有向角、一部分使用 `acos(|n̂·n|)`。圆周自转角对理想轴对称环不可观测，也不列作需要估计的输出。

目标中心误差历史要求为本批最大不超过4 mm，最好3 mm内，尚无实机独立验收。**法向2°、直径2 mm仅为暂定分析阈值建议**；正式门槛需工艺确认。除分项指标，还须检查目标圆周点的总偏差，因为分项预算会叠加：

```text
e_center = ||c_est-c_ref||
e_normal = |(c_est-c_ref)·n_ref|
e_tangent = ||(I-n_ref n_refᵀ)(c_est-c_ref)||
angle = acos(clamp(n_est·n_ref,-1,1))
e_radius = |r_est-r_ref|; e_diameter = 2 e_radius
```

由小角度几何，半径60 mm的环发生1°平面倾斜时，圆周相对圆心的法向高度变化幅度约 `r sin(1°)=1.047 mm`，对应两侧峰峰差约2.094 mm；2°对应约2.094 mm幅度。这里的1 mm是**单侧相对中心幅度**，不是整圈峰峰差。用于圆周点对应比较的保守一阶量级为 `e_center+e_radius+r·angle_rad`；不能给中心4 mm、半径1 mm、法向2°各自放满后仍声称整圈位置在4 mm内。

人工高对比环带、平面环形 coupon、理想掩码和精确投影边点均属于几何诊断。它们能够验证坐标、反投影、离散采样及求解器，却不能证明**自然陶瓷槽边可提取**，更不能证明槽底最小半径处恰好对应可见图像边缘。

## 2. 误差从物理定义传到输出的路径

```text
工艺截面定义与坛体真实形状
  → 可见性/表面反射/光照/遮挡/目标运动
  → RGB与深度各自成像、曝光时刻、光学模型和深度测量
  → RGB/depth几何关联与有效性检查
  → 圆/槽候选边缘、局部点云、轴对称轮廓
  → K/D/外参/尺度下的几何求解和鲁棒拒绝
  → 目标圆参数与条件不确定性
  → 独立计量坐标系中的实际误差
```

这条路径中至少有三种常见“低残差但误差大”的情况：所有相机共享同一错误世界变换；所有视图都选择了口沿或肩线而非窄槽截面；深度或标定尺度共同偏移。多次平均、增加相机和对已选边缘 bootstrap 都不能自动消除这些共同偏差。

| 误差项 | 固定/随机/相关性质 | 如何隔离与观察 | 当前证据/缺失 |
|---|---|---|---|
| 目标结构错选 | 通常固定偏差，可跨相机共同发生 | 槽底截面与上沿、下沿、口沿分别生成，报告错结构接受 | 用户目标已明确；真实轴向工艺位置仍需量测 |
| 圆度、平面度、歪颈 | 真实形状失配，常随物体固定 | 控制径向/轴向谐波；比较最佳圆与真实接触区域 | 历史已提醒不能假设理想圆；幅度未知 |
| K/D模型及参数 | 每相机固定；可能由共同板尺寸/平面误差相关 | 分开真值相机与虚拟标定；留出姿态；全视场投影模型检查 | 历史Brown5反解异常是具体项目证据，不能用旧RMS作准确度 |
| 外参与世界基准 | 固定；共享参考相机或板会引入相关项 | 独立每机扰动与共享刚体扰动分别施加 | 相机历史移动已知；本阶段不重用旧外参当当前真值 |
| 深度随机误差 | 像素/时间随机，通常各向异性、空间相关 | 重复帧估计时域，单帧平面估计空间域，视差域造噪 | 有D400官方良好纹理参考；实际陶瓷参数缺失 |
| 深度偏置/尺度/非线性 | 固定或随距离变化；可能批次相关 | 多已知距离、材质和角度；固定场景多帧不能单独识别尺度 | 有官方机制证据；本设备量值未知 |
| 空洞/离群/边缘混合 | 结构化、与遮挡/视角/材质相关 | 分别删整块区域、注入背景深度、模拟双视点遮挡 | MuJoCo同视点RGB/depth不能自然覆盖真实RGB-D错配 |
| RGB边缘/分割偏差 | 包含固定偏移与随机抖动；相邻像素和同一结构相关 | 有符号边缘偏移、光照改变、错线混入分别扫 | 历史侧视B将背景管道连入mask；精细槽边未证实 |
| 布局/可见弧 | 观测条件引发放大，不是可平均的噪声 | 同场景比较1/2/3机、基线、夹角、可见弧和条件数 | 不预设三机最优，需仿真与实际安装约束联合选择 |
| 运动/不同步 | 曝光时差可固定，帧间运动可随机 | 单列每机曝光时刻并使物体连续运动 | 当前研究静态主线；真实RGB无硬同步历史记录需复核 |
| 求解器/离散化 | 数值误差、局部最优、像素/网格偏差 | 连续真投影→无噪声渲染→实际提取逐级比对 | 必须避免把高分辨率或真值初始化当算法升级 |
| 独立量具/基准转换 | 参考自身也有不确定性 | 校准量具、重复装夹、独立拟合与误差传播 | 后续验收必须记录，不能视作零误差 |

## 3. 可解释的噪声模型

### 3.1 深度随机项从视差域开始

D400是双目深度。令 `d=f_x B/z`，一阶传播为：

```text
d_obs = d_true + b_d(u,v,z,camera) + eta_d
z_obs = f_x B / d_obs
sigma_z ≈ z² sigma_d/(f_x B)
```

其中 `eta_d` 是随机项，`b_d` 为固定/范围相关偏差。官方 [D400调优白皮书](https://realsense.intel.com/wp-content/uploads/sites/63/BKMs-For-Tuning-RealSense_D4xx_Cameras_WP_1.7.pdf)对良好纹理给出约0.05–0.1 px的亚像素RMS参考；它不是陶瓷槽边的标准差。仿真首轮可扫 `sigma_d={0.02,0.05,0.1,0.2} px`，其中0.02与0.2是压力扫描假设。虚拟基线 `B` 和焦距 `f_x` 必须写入配置；不能把没有双目基线定义的MuJoCo针孔深度，默认为本机D435测量。

深度误差沿像素射线传播；反投影 `p=[(u-cx)z/fx,(v-cy)z/fy,z]ᵀ` 后XYZ误差相关，不能独立给XYZ统一加同方差高斯。像素误差和深度误差也可能受同一失配影响；初始独立模型仅为消融起点。

若需直接测试偏置与尺度，另用 `z_meas=(1+s) z_true+b_z+eta_z` 做独立分支。这里的 `s,b_z` 不应与同一来源的 `b_d` 在无说明下重复计入。深度量化步长取保存的设备/仿真单位；把深度存储单位改细并不等于测量更准确。

官方 [亚像素线性白皮书](https://dev.realsenseai.com/docs/white-paper-subpixel-linearity-improvement-for-intel-realsense-depth-cameras/)展示特定设置在约1 m处具有周期偏差，说明固定非线性需要单测；不把其例图幅度直接当本机参数。官方 [D435/i质量摘要](https://support.realsenseai.com/hc/en-us/articles/360059129453-Depth-accuracy-for-Intel-RealSense-D400-Series-Cameras)的规定工况绝对误差规格与局部RMS不是同一量；2%既不是本实验应加的高斯sigma，也不是我们已达到的误差。

### 3.2 边缘与深度关联

图像候选边点可写为 `u_obs(s)=u_true(s)+[b_edge(s)+eta_edge(s)] n_image(s)`；`b_edge` 为沿整段轮廓的有符号偏移，`eta_edge`可独立或沿弧长相关。偏内/偏外会改变尺寸和距离，不能只用零均值抖动模拟。先分别扫0、±0.25、±0.5、±1 px固定偏移及0.1、0.3、0.7 px随机量级，全部为假设。

按针孔近轴近似，横向单像素量级为 `z/f`。举例若 `z=600 mm、f=450 px`（仅说明量级的假设值），1 px约1.33 mm；多视图深度误差还受基线/交会角放大，不可直接用这个比例验收三维圆心。

深度空洞至少分三类：随机缺点、连续可见弧缺失、RGB/深度双视点造成的遮挡无对应。离群至少分背景混入和孤立飞点。比例、块宽和相邻相关长度在未测量前全部标假设。[RealSense对齐与遮挡官方说明](https://dev.realsenseai.com/docs/projection-texture-mapping-and-occlusion-with-intel-realsense-depth-cameras/)解释了完美标定仍可能出现的几何遮挡；对齐孔洞不能通过拿真值表面补全后混进“实际提取”实验。

### 3.3 标定、坐标与相关项

外参从相机到世界为 `p_w=R_wc p_c+t_wc`，小扰动下 `delta p_w≈delta t-[R_wc p_c]_× delta phi+R_wc delta p_c`。旋转误差的影响取决于旋转支点与量测点的杠杆臂。例如0.5 m杠杆臂、0.1°小转角约0.87 mm，是量级计算而非所有布局的统一上限。

校准板的真实尺寸与求解器假定尺寸分开保存；若同比尺度误差为epsilon，米制外参平移与恢复尺寸可能产生同量级相对误差。虚拟板平面翘曲、角点检测误差、板姿态覆盖不足须分别加入。只有角点加噪的理想投影板是诊断，实际渲染板需跑角点检测，不能给求解器角点真值再称真实检测。

相机不确定性在一批试验中应保持固定：每个噪声重复先抽一次相机参数，再用该参数生成/解释该批多帧。逐帧重新抽外参会把系统误差变成可平均随机量，低估实际风险。共享参考相机/世界原点扰动应通过同一个随机变量施加到所有相机；校准板尺度也须作为共同变量。独立相机误差、共享误差和两者组合分别报告。

单一圆不足以自由优化全部相机、目标和绝对尺度。联合优化需固定规范自由度并给相机可信先验；多视图圆联合调整可参考 [Soheilian与Brédif原论文](https://isprs-annals.copernicus.org/articles/II-3/143/2014/)，其协方差仍依赖输入模型，不能涵盖未知错结构。

### 3.4 同步与形状失配

目标平移速度 `v` 与曝光时差 `delta t` 的一阶错位约为 `v delta t`；旋转时额外圆周量级约 `r omega delta t`。先做静态场景，再把运动与时差的符号、方向、每机时间写入配置。没有设备实际时间域/曝光资料时，不给出“本机同步误差分布”。

结构失配用径向 `r(theta)=r0+a2 cos(2theta+phi2)+...` 和轴向 `h(theta)` 参数化。谐波幅度、局部凹陷与槽宽并非传感器噪声；应与理想圆共享传感器条件比较。如果拟合圆仍有低残差但目标定义偏移，必须算作错误接受，而不是通过加大协方差消除问题。

## 4. 初始扫描清单与执行顺序

下面是设计范围；未注明来源的数字全部是**假设敏感度扫描**，不得写成D435的真实误差分布。每项先做正负扰动观察方向偏差，再做固定种子Monte Carlo。场景、扰动和随机样本ID应保留；最终测试使用不同目标位姿、尺寸及随机流，不能只换渲染帧号。

| 试验组 | 变量与起始范围 | 固定/随机设计 | 要回答的问题 |
|---|---|---|---|
| Z0理想闭环 | 真值相机、连续边点/理想掩码/实际RGB提取三级分开 | 无扰动，多位置/倾角/尺寸/布局 | 剩余误差来自求解、离散化还是提取？ |
| D1视差随机 | sigma_d 0.02/0.05/0.1/0.2 px | 像素独立起步，再加2/8/24 px相关块假设 | 异方差加权是否有效？点数增加是否只是假独立？ |
| D2深度系统 | b_z 0/±1/±3/±5 mm；s 0/±0.2/±0.5/±1% | 每相机每批固定，另做共同偏差 | 多帧/多相机是否隐藏而非消除偏差？ |
| C1内参 | f相对0/±0.1/±0.3/±1%；主点0/±0.2/±1/±2 px；畸变单项 | 每机固定，正负和边缘位置分层 | 哪类位置与姿态对内参误差最敏感？ |
| C2外参 | 平移0/±0.2/±1/±3 mm；转角0/±0.02/±0.1/±0.3° | 独立每机、共享参考、组合分别跑 | 三相机额外外参风险是否抵消观测收益？ |
| E1边缘 | 固定偏移与随机抖动用第3.2节范围 | 全弧共同偏移、局部相关、随机分开 | 鲁棒损失能否处理固定偏移？通常不能默认能 |
| E2缺失/离群 | 0/10/30/50%缺失或离群，另扫连续弧遮挡 | 随机与结构化分开；保留物理可见性 | 拒绝是否先于误差失控，错误接受是否增加？ |
| G1布局 | 1/2/3相机、近共线/短基线/互补方位、正视至近侧视 | 相同物体和噪声样本配对 | 观测加权、布局选择是否优于盲目加相机？ |
| B1虚拟板 | 尺寸误差、板翘曲、角点偏差、姿态覆盖 | 板真实几何固定、检测噪声变化 | 错误标定会不会保持低训练残差？ |
| M1形状/运动 | 圆度/平面度/截面偏移；v、omega、时差 | 每坛形状固定；运动单列 | 简化模型失配与异步各自的有效边界？ |

推荐顺序为 Z0→D1/D2→C1/C2→E1/E2→G1→少数组合→B1与M1。不要穷举全因子后只展示较好子集。对重要项给有限差分敏感度，例如中心毫米/每像素、法向度/外参转角，并绘制固定偏差的符号响应；非线性/拒绝区间应直接标出，不能用一条线性斜率概括。

鲁棒性消融至少包括：普通最小二乘、鲁棒损失、按测量模型加权、各视图质量拒绝、加入/移除深度、1/2/3机。采用同一测试案例和扰动实现配对比较。比较误差、错误接受、拒绝率和耗时；若只减少极端误差而大幅提高拒绝，必须同时展示。

## 5. 随机量、不确定性与报告

随机噪声可通过独立重复估计均值稳定性；固定偏置需独立基准校正；跨相机相关误差需显式联合模型。对相关样本不能按像素数量把协方差无限缩小。运行时质量只用可观测的残差、有效弧覆盖、几何条件、深度一致性和求解状态；真值只由评估器算标签。

每个开发/测试分组报告总数、接受数、拒绝数、正确接受数、错误接受数、以及符合误差要求但被拒绝的数量。建议同时给：

```text
成功率 = 正确接受数 / 总数
拒绝率 = 拒绝数 / 总数
错误接受占总数 = 错误接受数 / 总数
接受结果错误率 = 错误接受数 / 接受数   # 接受数为0时记NA
```

正确接受按事先固定的中心/角度/直径阈值联合判定；暂定角度/尺寸阈值需要明确标为研究建议。几何可定位性与物理结构身份分开标注；误识为口沿即使参数拟合稳定，也属于目标错误。

接受样本报中心三维/XYZ/法向/切向、角度、半径/直径误差的中位数、P95和最大值；给未接受原因统计。运行时间分渲染、提取、拟合，说明硬件、线程、预热和计时边界。没有接受的分组不报0误差。有限测试的最大值是本批最大观测误差，不是所有未来工况的保证。

若输出协方差或95%区间，在锁定测试中检查覆盖率；固定相机、只重采样边点得出的区间应叫“固定标定/结构下条件不确定性”。对新加入固定偏差/错结构的批次单独看覆盖率下降。残差小但实际偏差大应成为模型诊断证据，不能事后把区间扩大到覆盖所有真值后声称校准完成。

## 6. 后续实机独立验收计划（本阶段不执行）

**步骤A：先测量目标和参考件。** 为每只坛标出实际扎带位置，记录槽上/下边界、槽宽、槽底轮廓、圆度、平面度和口沿/颈轴关系。用经校验的独立量具或三维测量设备给出截面及坐标基准；必要时采用可追溯环形标准件/夹具做几何通道检查，再用无标记实际坛做可提取性验收。标准件、人工环带和coupon通过不代表自然窄槽通过。

**步骤B：单独测传感器和标定。** 在实际工作距离、分辨率、ROI、曝光/预设/滤波下，对纹理平面及近似陶瓷表面测每台深度的偏置、尺度、时域噪声、空间噪声、无效率和边缘混合。固定相机重拍与重新安装重标定分开统计。测标定板尺寸和平面度，保留原始RGB-D和角点；新姿态独立验证不要复用调参图。

**步骤C：预先锁定算法和门槛。** 用开发坛和开发场景定阈值，记录版本/配置/模型权重散列；测试坛及其位置、倾角、遮挡不得被调参使用。锁定后覆盖工位中心及边缘、低中高/近远距离、多个倾角与方位、多只坛，以及自然光照/反光/遮挡。每条件保留连续重复帧与重新摆放重复，区分帧内重复性和装夹/标定变化。

**步骤D：与独立真值比较。** 参考测量不确定度应显著小于目标容差；作为设计起点可争取位置扩展不确定度不大于约0.5–1 mm、角度不大于约0.2–0.5°、直径不大于约0.2–0.5 mm，这些是量具选型建议，不是已有设备能力。报告量具校准、装夹、坐标传递和参考圆拟合不确定性，并在边界附近采用明示的保守判定规则。

中心按3 mm理想目标和4 mm上限分别统计；法向2°/直径2 mm仍是待工艺批准的暂建议。同步报告圆周位置影响，避免分项阈值分别达标却不满足接触位置需求。保留全部拒绝、错结构和超差结果；报告P95/本批最大/成功率及其样本数。零次错误接受也不能解释成未来零风险，扩大样本与独立会话后再评估边界。

**步骤E：最后才评机器人应用。** 视觉世界坐标至机器人基座变换、活动TCP、运动误差和接触策略均另行验收；它们不能反向替代视觉圆参数的独立计量。当前仿真可行性、假设范围抗噪能力、实际坛的自然可提取性与实机应用有效性始终分开记录。

本文件列出的公式为明确简化模型下的一阶推导；引用的设备参考范围不构成本项目设备性能承诺。尚缺的真实噪声、形状与工艺截面资料均可在不接实机的阶段通过范围扫描开展研究，后续再用实测替换假设。
