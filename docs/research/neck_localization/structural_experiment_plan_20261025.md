# 结构候选与主动双目支持：本轮实验约定

用户授权2026-10-25离线自主实施。目标仍为凸唇下的扎带窄槽圆及3mm带宽，非坛口平面。
不连设备、不改变已有实机文件，不在独立仿真仓库工作，不覆盖历史算法/记录。

## 问题与顺序

1. 对既有4开发例作2×2真值干预：仅准确初值、仅准确外壁区域、两者、均无。
   真值仅指出像素归属或给初值，不用真值坐标替换测量。全部标为oracle诊断，不能报作算法成绩。
2. 从观测生成多个圆口/平面候选，按RGB几何支持与下方窄结构筛选。借鉴CN122289742A的候选/结构验证思想，
   不照搬含义不明的体积密度和评分公式，也不声称完整复现该申请。
3. 对实际深度作低自由度鲁棒轴/曲线估计，保留普通权重、Huber、区域反馈和单候选消融。
   噪声条件下的质量判断另设明确假设，不能直接沿用理想0.4mm残差门槛，更不能按目标真值放行。
4. 如果oracle仍失败，在同一IR图、同一内部噪声种子上，比较匹配支持尺寸，默认重放须逐像素复现。
   改匹配算法不等于提高仿真分辨率或关闭噪声；它也不代表实机D435固件可采用同一设置。
5. 开发期可尝试RGB直接重投影/轮廓约束；若理想输入已偏差明显或出现错误接受，不设默认。

## 数据隔离与结论边界

- 既有4开发+8已看测试，均仅能用于开发/诊断。
- 新评估事先生成配置，另用固定种子；估计器及阈值在新案例渲染/读取评价前冻结。
- 固定旧0.8m三相机位置和分辨率、同一照片参考圆截面模型族；不做布局搜索。
- 主评估仍为准确K/T，主动双目有内部speckle/thermal和匹配错误。不得称包含了实机所有标定/材料/同步误差。
- 主结果计入全部案例：正确接受、拒绝、错误接受；有圆但拒绝也报告其误差，无圆不当成零。
- 中心≤4mm、法向≤2°、直径≤2mm；后两项仍为分析建议。法向指向世界+Z。
- 3mm整带包含另报；半径误差、法向/切向/分轴、P50/P95/最大及耗时均保留。
- 不把小样本成功比例当工厂长期可靠性，也不输出未校准的统计置信度。
