# 第一项传感器约束：固定深度偏差敏感度

2026-10-23。用户同意逐步加入现实约束。本步仅加入相机轴向深度固定偏差；不改冻结定位器、
不调质量阈值、不加入标定/输送/机器人或随机误差。带宽3 mm，选取模型完整颈段≥6 mm的案例。
**结论：理想几何的成功率不能延续为抗偏差成功率。当前系统同时存在拒绝正确候选和接受尺寸超差候选。**

## 1. 为什么先做这一项，参数从哪里来

[官方Depth Testing Methodology](https://cdrdv2-public.intel.com/841706/RealSense_DepthQualityTesting.pdf)
区分Z精度、空间RMS与时间噪声，并要求已知距离等独立参考条件。
[D400 Subpixel Linearity白皮书，修订1.3](https://www.realsenseai.com/wp-content/uploads/2019/07/White_Paper_on_Subpixel_Linearity_Improvement-1.pdf)
区分随距离变化的标定斜率/偏移与子像素非线性，并说明某些情况下很小的RMS仍可伴随错误深度。
这些文献支持区分固定偏差与随机起伏，**不提供本项目当前相机在陶瓷颈部的实测偏差量值**。

本轮±1/±2/±4 mm是按任务毫米级预算设置的假设敏感度档位，不是设备规格、实测分布或发生概率。
没有用论文中的其他设备/预设/距离数字冒充我们手头相机的性能。
偏差实际可能来自多项标定与测量机制；本步仅隔离轴向Z加性偏移，不模拟全部机制。

## 2. 模型和实验控制

像素齐次坐标u、相机内参K、相机到世界变换(R,t)，原点云为

$$p_W=R(zK^{-1}u)+t.$$

对相机j报告的光轴深度加常数b_j：z'=z+b_j，则

$$\Delta p_W=b_jRK^{-1}u.$$

因此它沿对应像素的视线改变三维点，**不是给世界Z统一平移，也不是给欧氏测距加同样数值**。
相同b在三台不同朝向相机里不对应同一个世界平移；融合后可能改变半径、轴与跨相机一致性。
四项新测试包含上述传播公式核对。

`depth_perturbation.axial_depth_bias`只读观测，不访问目标、网格或模型尺寸。
对整张图的有效正深度加偏差（含背景），而非按真值掩码只改坛颈；0/负值/NaN/Inf不被补成测量。
极端负偏差导致非正测量时标无效，本批没有这种情况。零对照保留原dtype和值，非零用float64，
不混入深度量化实验；RGB、K/T、布局、光照、几何保持不变，所有相机信任系数仍为1。
MuJoCo仍是同视点RGB/深度；真实深度到RGB对齐误差、立体匹配/投影器效应不在本步内。

## 4. 可以确认的薄弱环节与尚未解决的问题

**共同偏差会主要表现为尺寸系统误差。**11个±1 mm两侧都有解的案例，有符号直径误差对偏差的
中心差分斜率中位−1.570 mm/mm，范围−1.589至−1.543。这是当前布局/模型的观测结果，不能外推为所有布局公式。
共同深度偏大时，当前视线会把多侧表面向内推，拟合出偏小的半径；多相机并未消掉它。

**小残差仍可能接受偏差结果。**nominal_002在三机+2 mm时：圆心0.323 mm、法向0.279°，
直径误差3.106 mm；留出RMS为0.386 mm，略低于旧0.4 mm门槛，故被接受。
按暂定直径2 mm阈值它是错误接受，但尚未证明真实3 mm带材一定扎带失败，径向贴合/工具模型未做。
这说明同一偏差污染下的条件留出残差不能独立验证绝对尺寸。

**质量判据也拒绝了本批符合几何阈值的候选。**仅A+2 mm时12个候选均满足当前几何阈值且轴向整带容纳，
却全部因模型/目标读出残差拒绝；仅A−2 mm有11个这类候选，另1例无解。
例如nominal_001仅A+2 mm：圆心0.901、直径0.976 mm，留出RMS0.487 mm，超过旧0.4门槛。
这是固定偏差造成的跨相机模型不一致；不能直接把观察到的几何合格倒灌成上线放行规则。

**端点支持仍会受小扰动影响。**stress_003在三机+1 mm即因近最细区间触及搜索边界而拒绝，
同帧28/42/56 mm和备用轴均未通过。它的物理颈段21.825 mm，并非带宽太大或颈长不足。
目前证据是已有支持/读出机制在有偏深度下失效，未进一步证明其全是局部最优或某一单独阈值的责任。

本步只识别问题，未实施补偿、放宽门槛、降低半径要求或以真值偏差校正。
下一轮先分析相机偏差与真实半径/轮廓能否同时辨识，以及需要什么独立约束；
再比较有依据的偏差补偿、观测一致性与误差感知质量判据。
不能把每个非标准坛的未知真实半径当已知，也不能假定只靠拟合残差就能自行标定所有偏差。
若改算法，这108条是开发诊断，另锁新的≥6 mm几何与扰动条件评价，不重复称未见测试。
