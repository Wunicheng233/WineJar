# 传感器模型选型：先复用已有方法

2026-10-24。根据用户纠正重新定向。本轮只核查文献与源码，未安装新仿真器、运行新精度实验或连接设备。

本文件保留选型时状态；后续实施及负结果见[2026-10-25完成报告](active_stereo_results_20261025.md)。

## 当前决定

固定深度偏移只保留为机理诊断，不再作为现实传感器模型的主线。
之前虽列出误差资料，但没有充分落实为成熟模型及实现的复用对照，这一点需要纠正。
下一阶段先选已有的成像仿真、标定和补偿方法，再评估它们在短颈任务中的局限。
区分误差来源不要求三个独立算法；统一优化或同一个学习模型都可作为候选。

历史三相机内参JSON中的设备名均为 Intel RealSense D435I，例如
`xarm_sdk_control/calibration/multiview_neck/side_a_intrinsics_20260901_220838_167.json`。
这是历史设备证据，不代表当前硬件状态。文件中的棋盘内参属于RGB，不能直接充当左右IR内参或内部基线。

## 优先候选及边界

### 1. 主动双目测量生成：SAPIEN / SimSense

**原文依据：**[作者项目](https://angli66.github.io/active-sensor-sim/)，
[可访问原文v2，第6–7节](https://arxiv.org/html/2201.11924v2)。
管线包括材料/红外投影与成像、IR强度噪声、Census/半全局双目匹配及亚像素视差。
深度错误及缺失由成像和匹配产生，而非直接在理想深度上统一加噪声。原文实验设备为D415，IR噪声参数来自其采样。

**代码依据：**[当前维护源码](https://github.com/haosulab/SAPIEN/blob/master/python/py_package/sensor/stereodepth.py)
包含D415、D435预设及D435投影图案；本次核查该文件最近修改提交为
`8360d517770f24f00bacef7d906ddf1380b8967c`，
[固定文件链接](https://github.com/haosulab/SAPIEN/blob/8360d517770f24f00bacef7d906ddf1380b8967c/python/py_package/sensor/stereodepth.py)。
文档站旧版仍仅显示D415配置，选型必须核对发布版本及全部依赖，不能只照旧文档。

**项目判断：**优先验证这一现成传感器后端。D435预设不是本机D435i的已验证数字孪生；
还需核对模式、RGB/IR参数、材料红外响应、噪声和匹配配置。照片的可见光颜色不能直接确定红外反射率。
MuJoCo现有模型、真值与查看器保留；若采用独立渲染后端，须先核对同一网格、位姿、坐标系和深度定义。
此刻未决定迁移场景，更未验证本任务精度。

### 2. 系统误差补偿：RGB-D联合标定

**原文依据：**Basso等，TRO2018，[原文](https://arxiv.org/html/1701.05748)，
[作者实现](https://iaslab-unipd.github.io/rgbd_calibration/)。
使用局部深度畸变映射和全局校正映射，联合细化RGB–depth位姿等参数，表达随像素和深度变化的系统误差。
需要预先校准RGB、带棋盘的平面、多距离多方向RGB-D采样。作者代码为BSD，依赖ROS Indigo/PCL/Ceres等。
原文评估Kinect1/2、Asus，未直接验证D435；其结果不能作为本项目毫米精度承诺。

**项目判断：**作为复杂补偿的优先传统基线；先在独立虚拟标定场景求参数，锁定后测试未知酒坛。
生成模型和补偿模型须有不匹配对照，不能只用同一函数生成再反解以制造好结果。
现有从酒坛估计三常数偏移的方法只作为任务内补偿对照，不替代独立标定。

### 3. 厂商校准及后处理：librealsense

**官方依据：**[D400 Self-Calibration/Tare](https://dev.realsenseai.com/docs/intel-realsense-self-calibration-for-d400-series-depth-cameras/)，
[后处理实现说明](https://github.com/realsenseai/librealsense/blob/master/doc/post-processing-filters.md)。
已有片上校准、需要真实距离参考的Tare，以及空间、时间、孔洞等独立处理模块。
这些不负责相机阵列到工位/机械臂的外参，也不保证任意场景的深度无误。
时间滤波依赖历史帧，官方说明可能出现拖影。

**项目判断：**优先把官方空间/视差域滤波作为现成对照；保留原始图和处理图。
在仅约6 mm颈段上，平滑或补洞可能改变窄结构，应以目标圆及3 mm整带误差验收，不能只看点云更光滑。
这是待验证风险，没有在本轮测出损失。每坛一次识别不默认允许多帧时间滤波。
设备校准仅作为后续现场计划，本轮不执行、不写设备参数。

### 4. 学习式补偿备选

Heindl等，[论文](https://arxiv.org/abs/1907.00549)、[作者源码与数据](https://github.com/cheind/rgbd-correction)，
用GP学习空间、距离和温度相关深度修正及条件预测方差。
它说明复杂补偿已有监督回归路线，不必先上RL。实验为Orbbec结构光设备，不能沿用预训练参数；
本项目只有在确有温度输入与效应证据时才加入温度项。预测方差也不等于完整任务不确定性。

## 接下来的最小闭环（尚未执行）

1. 固定SAPIEN/SimSense候选版本，核查D435模式与依赖可运行性；先比较同一简单平面、台阶和圆柱的理想深度与匹配深度。
2. 分别记录距离偏差、平面空间噪声、缺失率、边缘位移及相关性；对短颈尤其检查结构是否被匹配窗口/滤波抹去。
3. 单独准备多距离、多方向虚拟标定板，估计校正模型与相机参数；区分生成真值和传给估计器的标定估计值。
4. 在冻结的新酒坛测试上比较：原始测量→既有定位、官方后处理→定位、离线校正→定位、再加任务内补偿。
   报正确输出、错误接受、拒绝、整带余量和耗时；不只报传感器残差。
5. 当前无法实测的本机材料/IR/噪声参数列为待识别量，有来源的默认值与假设扫描分开。
   离线可验证方法机制与参数敏感度，不能因此声称仿真已代表本机。

不继续逐个发明无来源的深度扰动，也不一次混入所有未知效应。分项消融仍保留，但改为有文献/设备依据的机制。

## 创新判据

现成方法能达到任务要求，就优先采用。效果差先排除移植错误、参考不准和不合适参数，
再确认在合理设置、独立场景中可重复出现的局限。未找到软件包或首次用于酒坛都不能单独证明创新。
待证问题可表述为：有限视角、非标准局部窄颈上，系统偏差与真实形状差异如何区分，
以及传感器校正和局部几何估计能否共同提高整条带落入可用区域的可靠性。
这是研究候选，不是已证实文献空白。
