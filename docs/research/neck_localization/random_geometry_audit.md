# 随机坛型审计与下一阶段顺序

2026-10-23。用户希望查看更多随机不同酒坛，并讨论后续精度、抗噪与速度优先级。
本阶段只扩大几何评价；算法、相机、分辨率、真值和判据保持上一轮冻结，不实施噪声扫描或速度优化。

## 1. 这次实际做了什么

固定种子2026102327，生成36个此前未评价的坛型，比较`fixed_equal_trust`与`region_equal_trust`，
一/二/三相机各一次，共216条记录。配置及源码散列在生成场景和读取评价结果前写入plan.json。
所有采样案例保留，没有根据算法结果重抽、筛选或调参。

24个`nominal`：假设常规范围，坛高570–650 mm、坛身半径165–195 mm、颈半径48–57 mm、
短颈8–14 mm、口沿高5–7 mm、倾斜分量向量幅度0–7°、口颈XY偏移各±5 mm。
12个`stress`：假设压力范围，坛高550–680 mm、短颈4.5–7或16–22 mm、倾斜分量幅度8–12°、
口颈偏移各±10 mm，其余尺寸范围略扩大。倾角由X/Y分量表示，真实总倾角由模型旋转确定。
两组都随机平底/浅凹颈部、坛身宽度和母线比例、口沿尺寸及材质斑驳。

这些范围不是工厂测量分布，常规/压力标签不代表实际出现频率。
坛底摆放、场景和三相机布局均固定；改变的是不同坛子的局部几何，而非同坛重复摆放。
依然是已有圆截面模型家族：没有椭圆、周向凹凸、多槽、不规则口沿或真实深度/反光误差。
因此它比六个手选案例更广，但不能作为真实非标准酒坛泛化证据。

## 2. 区域策略的结果

成功=算法接受且满足圆心4 mm/法向2°/直径2 mm的分析阈值，后两项仍非工艺验收定案。
所有尝试进入分母；错误接受指接受但超阈值，拒绝不隐去。

误差统计包含可求出的拒绝候选；无输出的拒绝不填零。
压力单视图误差只来自3个可求解案例，不能因其误差小而称优于三视图，必须同时看9次拒绝。
三视图直径最大误差常规0.029 mm、压力0.097 mm；完整两方法/所有记录见结果表。
这些是小规模假设分布下的经验量，最大/P95不是总体保证，零错误接受不是实机可靠性保证。
本轮未估计校准不确定性。

固定权重对照三视图也是常规23接受/1拒绝、压力11接受/1拒绝，但拒绝个体和误差可能不同；
不能仅靠成功率区分方法。三相机在此固定布局下更常获得足够支持，不证明数量或布局最优。
全部216次两方法评价都未出现分析阈值下的错误接受，不代表现实误差链路已覆盖。

## 5. 下一步建议

优先顺序是：**明确失效边界并解决具体稳定性问题 → 有依据的深度偏差实验 → 按工位时限优化速度**。

1. 本轮已扩大几何覆盖，下一小步先处理离散区域反馈两周期，检查候选范围对颈长的适用性。
   保留拒绝与异常可视化，用开发案例定位，修正后另锁新案例。
   同时厘清作业范围端点定义及误差组成；不追求通过改真值获得更漂亮仿真误差。
2. 随后先做少量、单因素的深度固定偏差/尺度误差敏感度，再考虑空间相关误差、边缘失效和随机误差。
   参数没有实测依据时明确是范围扫描，不能假装RealSense传感器模型。参考既有误差预算。
   不先给所有点统一添加独立高斯噪声，因为固定/共享偏差更可能暴露当前几何拟合的实际短板。
3. 当前本机三视图估计中位数约0.34–0.35秒，不含采集、传输和渲染，也不是工位延迟保证。
   先明确允许识别时窗并测完整链路；如不够，再做剖析和等精度耗时消融。
   尚无时间预算，不能现在为了更快削减有效信息。初值数、样本量和停止条件均需用可靠性约束评价。

模型错配和真实误差还未闭合；少量论文候选问题可以围绕支持区域的可确定性、拒绝与相关偏差，
不能以漂亮单例或本轮同一模型家族的统计代替实机有效性或创新性证据。
