# 夜间研究结果：不确定性、显式偏差补偿与残差学习取舍

2026-10-24。用户授权自主离线调研、对比和调试。本轮没有连接或操作相机/机械臂，原13个冻结源文件不改，未提交推送。
采用3 mm轴向带宽、模型颈段至少6 mm；其他形状范围仍为假设，不是工厂分布。

## 先看结论

1. **纯加性轴向深度偏差、准确K/T、圆截面模型下，显式偏差补偿有效。**首次新16坛型128条件为127正确/1拒绝，
   无错误接受；旧法16正确/82拒绝/30错误接受。独立第二批新8坛型40条件为40正确/0拒绝/0错误接受，旧法8正确/32拒绝。
2. **还没有解决通用标定误差或实机不确定性。**共享世界外参平移5 mm时，新旧方法均错误接受；焦距模型失配时补偿可能加重尺寸误差。
   圆拟合好了并不说明估出的每相机参数就是准确的设备标定值。
3. **残差RL可行性不能因“一坛只采一次”排除。**固定观测可以做软件多步动作，但目前先用可解释的低维模型取得了改善；没有训练网络或RL。
   详细原文/官方代码调研见[专项报告](uncertainty_methods_review.md)，不把未训练解释为RL无效。

## 1. 新系统到底加了什么

保留原V2作为底座，流程为：

```text
原始RGB-D + 给定相机K/T
 → 原V2观测初始化、局部点集和权重（失败时可只做观测初始化）
 → 联合解局部轴4变量 + 每相机未知深度偏差3变量 + 自由样条轮廓
 → 条件留出误差、数据退化、求解状态/边界检查
 → 沿每个像素射线减去估计偏差，生成补偿深度
 → 重新运行冻结V2 + 原质量阈值 + 3 mm带宽判据
```

不是根据真值移动最终圆。未知半径不固定；真实坛径、注入偏差、目标圆和模型颈段边界不提供给求解器。
三台偏差分别自由估计，不告知哪台坏了，也不强迫三机偏差相等。样条系数通过QR变量投影消去，
求解器使用解析雅可比（含变量投影两项与观测点随偏差移动的导数）。

对第j台相机的观测点，补偿为p_i(b)=p_i,meas−b_j R_j K_j^{-1}u_i。
主版本不使用偏差先验；消融版假设sigma_b=2 mm、sigma_data=0.1 mm，**均不是设备实测值**。
相机信任均为1；现有区域权重仍非经过标定的测量方差权重。

源码：`neck_localization/bias_profile.py`、`bias_compensation.py`。
补偿后不通过旧质量判据时不会强行输出；若原始候选已接受则保留它作为观测可实施的备用，不使用真值选候选。
原残差0.4 mm等门槛未放宽。本轮并未给这些门槛建立概率含义。

为保留冻结版本，Python函数默认仍是旧70次/弱先验设置；最新版本由计划显式指定
`BiasCompensationSettings(sigma_bias_mm=None, maximum_evaluations=200)`。不要把默认调用误认成最新主版本。

## 2. 为什么在当前观测下能估偏差，何时会退化

不把整个坛视为已知CAD，而利用局部圆截面的几何一致性。轴/曲线和相机偏差虽耦合，
在当前三视图所见圆弧足够宽时，不完全等价。测试数据雅可比时投影掉样条干扰，**不把平滑项或校准先验算作数据可辨识性**。

4个旧例的观测圆弧诊断（半角相对朝向相机的外壁方向，非移动相机）：

| 保留圆弧半角 | 自然点数：条件数中位 | 每机相同固定点数：条件数中位 |
|---:|---:|---:|
| 85° | 19.65 | 19.50 |
| 45° | 46.09 | 43.52 |
| 20° | 155.01 | 161.46 |
| 10° | 285.86 | 303.24 |
| 5° | 478.56 | 465.39 |

缩窄圆弧时，形状/偏差分离变差，即使控制点数仍如此。该条件数使用固定参数尺度，只是局部诊断；
它不证明全局唯一最优、不等于毫米精度，也不包含区间端点/绝对世界基准误差。
没有搜索相机布局。图与全部40条记录：`results/bias_observability_20261024/`。

解析导数做了4项测试及真实观测的多步长差分扫描。
首次用所有变量同样1e−5步长，有3个元素未通过严格误差门槛；扫描显示角度变量的截断误差明显，
改用平移/偏差1e−4、法向切向变量1e−6后通过。不是放弃失败的导数检查；收敛曲线及原数值保留。

## 3. 开发与两批独立评价，失败结果保留

正确输出沿用圆心≤4 mm、法向≤2°、直径≤2 mm；后两项仍为分析阈值。
整任务还要求估计标记兼容、整条3 mm带位于真值区间，分别按近最细代理和完整颈段假设评价。
本轮三套比较中整任务正确输出数与圆正确输出数相同，拒绝都计失败。

| 批次 | 方法 | 正确/总数 | 拒绝 | 错误接受 |
|---|---|---:|---:|---:|
| 旧12坛型×9档，开发 | 原V2 | 35/108 | 72 | 1 |
| 同上 | 无先验 / 弱先验补偿 | 各108/108 | 0 | 0 |
| 新16坛型×8档，首次冻结测试 | 原V2 | 16/128 | 82 | 30 |
| 同上 | 无先验 / 弱先验补偿，70次预算 | 各127/128 | 1 | 0 |
| 再新8坛型×5档，第二次冻结测试 | 原V2 | 8/40 | 32 | 0 |
| 同上 | 无先验补偿，70次预算 | 40/40 | 0 | 0 |
| 同上 | 无先验补偿，200次预算，最新主版本 | 40/40 | 0 | 0 |

首次新测试：种子2026102421；新8常规+8压力，常规颈段6–14 mm，压力6–7/16–22 mm；
偏差为零、三机共同±1.5/±3 mm、仅B+3、仅C−3、A+2/B−2/C+1。
算法/参数先冻结再评分，无先验版事先选为主方法；弱先验未显示明显额外收益，仅代表这个很弱的假设强度。

唯一失败是stress_003/only_c_m3。估出的偏差[0.0079,0.0009,−3.0527] mm，
留出RMS从0.393降至0.079 mm，但70次预算未收敛，因此未采用补偿，返回原范围边界拒绝。
这不能隐藏或改计成功。该案例随后转为开发诊断：70/140仍未结束，280上限时实际150次收敛，圆心0.811 mm。

据此只改变求解预算上限为200，不改质量阈值，并再锁种子2026102441、全新4常规+4压力。
第二批偏差：零、共同±2.5 mm、仅C−3.5、A+1.7/B−2.3/C+0.6。
两预算版这批均通过，且输出完全相同，**不能把第二批40/40与第一批127/128直接相减，声称测得增加预算的成功率收益**。
第一批现在已查看，后续调整不得再次将它称作未见测试。

同一坛型的多扰动条件相关；128或40不是相同数量的独立工厂酒坛，更不是工业百万次可靠性证明。
本轮没改变圆截面模型族，测量误差机制也匹配所解的加性模型，仿真成绩不能当实机绝对精度。

## 4. 标定/噪声模型失配反例

4个旧开发坛型分别施加一种误差，随机项固定种子，未据此调主算法：

| 假设诊断因素 | 原V2正确/4 | 补偿正确/4 | 关键发现 |
|---|---:|---:|---|
| 无扰动 | 4 | 4 | 基本对照 |
| 深度尺度+0.3% | 0 | 4 | 此范围内加性局部补偿有帮助，不等于识别了正确尺度模型 |
| 用于反投影的焦距参数+0.5% | 4 | 4 | 最大直径误差从0.194增至0.753 mm，补偿可加重尺寸偏差 |
| A相机外参世界X+2 mm | 0 | 4 | 输出达阈值，但偏差变量不是实际外参修复 |
| 所有相机外参世界X+5 mm | 0 | 0 | 两法均4次错误接受，圆心约偏5 mm、残差几乎不变 |
| 独立视差噪声sigma=0.01 px | 4 | 4 | 只有很弱的假设随机项，不能推断真实抗噪能力 |

最后一项用真实合成fx、假设双目基线0.05 m，在视差域加独立Gaussian后反算深度；无空间相关、无立体匹配失效，
不是给所有因素统一加三维高斯。焦距实验只改变重建参数，不是完整双目硬件/标定联合仿真。

共享外参变换G有严格歧义：若T_j都改成G T_j，未知物体几何也一起变换G，内部几何残差不变。
不能由同一批未知坛型点云决定哪个世界基准才正确；需要外部工位/机器人/输送基准约束。
8个新旧方法×案例的显式运行对照验证圆心随之平移5 mm。
增加点、换优化器、训练残差网络或RL，都不能在相同信息下凭空恢复这个绝对基准。

这里保持模拟器评价世界W固定，仅把相机到W的估计外参共同改错；没有同时改变真值物体或另一个执行基准。
若相机、物体、机器人都一致地乘同一个G，那只是坐标重命名，不是物理定位误差。
未来相机→W→机器人链中，共享的标定项可能部分抵消，必须保留相关性，不能重复计入预算。
已知工位标志/支撑面/精确夹具也可以提供部分外部约束；当前定位器没有使用这些毫米级绝对锚点。

原始参数/深度及记录：`runs/bias_model_mismatch_20261024_v1/`；
汇总与歧义核对：`results/bias_model_mismatch_20261024/`。

## 5. 不确定性目前做到了哪一步

新增共享SE(3)参考误差传播模块：扰动按世界原点左乘，xi=[世界平移m,世界小旋转rad]，
J_c=[I,−[c]×]、J_n=[0,−[n]×]，输出中心/法向联合协方差及交叉项。
它需要外部提供可信校准协方差；**不是从当前点云自动估出了真实校准协方差**。
协方差应使用同一固定参考、扰动方向与原点；将来换到机器人相对坐标时还须传播交叉相关，而非把坐标选择本身算误差。

另做4096样本/案例的共同平移Monte-Carlo算术诊断，用已有输出的精确平移性质，不冒称重新运行了数万次定位器：

| 假设共同平移每轴sigma mm | 仅共同项+既有估计偏差的95%椭球覆盖 | 错误按拟合点数缩小后的覆盖 |
|---:|---:|---:|
| 0.5 | 82.79% | 0.010% |
| 1 | 92.88% | 0.014% |
| 2 | 94.86% | 0.016% |

理想零估计偏差的诊断覆盖95.53%，符合采样波动。第一列仍未达到95%，尤其sigma小时，
是因为既有固定估计偏差没有被这个共同项覆盖；不能把它叫完整系统置信度。
第二列说明共享校准误差不能按点数平均掉；协方差变小也不等于定位更准。
这些sigma是人为先验，不是测得设备概率；角度/深度/范围端点误差未包含在该Monte-Carlo中。

**定位器输出仍标不确定性未校准。**本轮真正改善了特定偏差下的点估计，没有完成统一误差模型或置信度校准。

新测试覆盖变量投影解析导数、零偏差与原模型一致、各相机射线修正、先验不计入数据可辨识性、

本轮48项核心与3项查看器/3子检查通过；552组补偿输入和550组有几何候选的拟合点逐点对齐。
最新一键命令已完整实际运行，包括重新渲染场景、40条原算法和80条补偿对照；
与原运行逐项比较时只排除耗时，原始RGB/深度也单独核对。开发和首次128条件没有完整第二遍重跑。

下一步优先级：

1. 按真实链路分别建内参/畸变/外参/深度尺度模型，用虚拟标定板求参，与真值相机实验分开；明确外部世界基准与共享误差。
2. 非圆/局部变形与颈段定义不一致不能全由偏差参数吸收；加入形状失配并保留有偏接受反例，再谈可用于工艺的置信度。
3. 依据真实或明确假设的随机/相关项做不确定性传播、独立覆盖率和整带可靠性检查；避免盲目扩大拒绝。
4. 以时间窗口决定是否做快速初始化/计算预算优化；之后才比较监督残差和软件RL的收益与训练成本。
5. 传送带与工具坐标链按既有契约另阶段实现；本轮未做机械臂或真实带材接触/张力验收。

相机偏差估计、区域反馈、残差学习、不确定性或轴对称BA均已有先例。本轮是可信原型与问题定位，尚无论文新颖性或可发表性证明。
