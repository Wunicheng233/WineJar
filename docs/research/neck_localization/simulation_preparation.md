# 酒坛模型与静态仿真场景准备

更新：2026-10-22。当前范围为**参数化酒坛重建、静态相机场景、渲染预览和几何检查**。
本文描述模型与场景准备。用户后续授权自主仿真/调试后，已完成[首轮理想深度闭环](short_neck_baseline.md)；
本轮没有新增完整噪声矩阵，也不连接实机。
这份文件承接[最小模型](minimal_model.md)与[视觉方案](visual_proposal.md)，按用户要求逐阶段推进。

## 本轮已经确认的建模选择

用户接受以局部颈轴和截面半径描述坛颈，并先采用标准圆截面；椭圆留作后续模型失配/扩展选项。
用户提出：没有唯一最细候选时，寻找最细颈部的一个范围，输出其均值或中间位置。
本轮据此准备模型与范围真值，不先把图像中的一条锐边当作目标圆。

一个截面上半径为常数，表示该截面是圆；这与整段坛颈的`r(s)`都是常数不同。
后者表示圆柱，单靠半径无法决定该段中哪一轴向位置是作业截面。
因此保留沿轴变化的`r(s)`，先使每个给定`s`上的截面为圆：

```text
X(s, θ) = c(s) + r(s) [u(s) cos θ + v(s) sin θ]
```

首版用于估计讨论的局部直颈满足`c(s)=a+s n`，`n`既是颈轴方向也是各截面的法向，
`u × v = n`，并约定`n · world_up > 0`。这是**局部直轴模型的定义**，不是酒坛任意表面
的法向，也不推出坛身轴、口沿平面与颈轴必须一致。生成模型可在肩部向倾斜颈部平滑过渡，
不要简单旋转整只酒坛来冒充个体歪颈。用户进一步纠正后，已取消会弯曲上半坛身的过渡：
仅口颈附近截面逐渐转动，形成一侧高、一侧低；5°/-3°示例在距坛底567.25 mm以下与正常坛型逐顶点相同。
连接圈内截面方向独立于中心线切向，不把二者混作一条弯轴；直颈内部仍一致。

## 最细范围与中间位置的计算约定

应区分“模型上存在一个最低值”与“观测足以可靠确定一个最细范围”。在完整生成模型中，
可以计算最小值，但未来估计器只能使用观测，无法因总能计算出最小值就宣布定位可靠。

范围必须位于口唇下的局部颈区`D`，不能在整坛上求全局最小半径。可采用以下可复现约定：

1. 对确实具有平底的生成模型，直接记录所建平底的闭区间`[s_lo, s_hi]`，作为生成器真值。
2. 对一般平滑形状，可定义`r_min = min_D r(s)`，并以`r(s) ≤ r_min + ε_r`的连续分量
   定义“近最细范围”。`ε_r`以半径的长度单位给定、写入配置，不能从期望答案倒调。
3. 选择与目标缩颈对应的连续分量；若存在多个分离候选，保留多解，不把它们跨空档连成一个范围。
4. 对单一可信范围，目标轴向位置为`s_mid=(s_lo+s_hi)/2`，而非对不均匀采样点直接取算术平均。
   直轴模型给出`c_mid=a+s_mid n`、法向`n`和`r(s_mid)`；范围长度另行输出。

`ε_r`及范围和实际带宽的关系尚未工艺定标。首版若采用某一值，只是预览/QC规则，不能声称
已经确定实机允许范围。唯一最小值加正阈值也可以形成近最细范围，但宽度会依赖阈值与槽底曲率。

缺少槽区观测、范围触及搜索域边界、多分量无法区分、局部近圆假设失效，或颈部在可见域内
只是单调收缩时，不能保证存在**可靠的闭合范围**；将来需要输出无法确定的原因。
用户选用中点规则简化了平底的代表位置选择，并没有消除范围边界的不确定性。

## 场景准备与真值隔离

工位设为固定底座/传送带平面、清楚的单色背景和稳定照明。每个模型使用同一摆放规则，
跨模型改变个体高度、颈部位置、半径剖面与局部倾斜，避免混成同坛随机摆放实验。
本阶段先冻结场景，不加入传送带运动、同步误差或多次重拍。

- 先准备两台固定侧向相机，具备明显方位差且能看到口唇下方；第三视图单独保留作布局对照。
  初始位置只是候选布局，不宣称已最优或已能完整看到槽区。
  以世界位置`[0, 0, 0.590] m`作为当前0.60 m名义坛高下的初始共同瞄准点；最终瞄准点随
  场景配置保存，一经确定不按各case的目标真值重新转向或平移相机。它是固定工位的布局参考，
  不提供给估计器作目标初值，也不代表不同个体的实际目标中心均位于此点。
- 使用MuJoCo渲染RGB与浮点深度；相机参数、图像分辨率、单位、坐标变换和深度含义随场景保存。
  统一针孔RGB-D渲染是几何准备条件，不代表复现了RealSense的双目匹配、RGB/深度基线和实际误差。
- 保留口唇、肩部及开口几何，让自遮挡由渲染器自然产生。不能因目标需要可见而关闭遮挡。
- RGB中不在目标位置设置人工亮环、专属颜色或随目标标签移动的材质分界。
  斑驳材质只是外观变化，不当作真实反射/釉面成像模型。
- 精确形状、圆与范围真值只属于生成器与后续评估器。预览若显示坐标轴/真值叠图，
  必须标成几何诊断图，并与未来估计器输入分开；渲染原图不得带真值标记。
- GT掩码/目标可见性统计可用于准备阶段的渲染检查，不能改称自然图像提取结果。

## 本阶段的三项检查边界

1. **几何正确。** 主体、肩部、颈部和口唇衔接无穿插；圆/范围位于定义的颈区；
   歪颈是局部形状变化；法向和长度单位一致。
2. **观测正确。** 每台相机实际渲染什么就使用什么；检查槽区可见情况、画幅裁切、深度值及
   RGB对应关系，不使用被遮住的解析圆弧替代可见观测。
3. **结论正确。** 把照片启发与实测重建、理想针孔RGB-D与RealSense、圆直颈假设与任意坛形、
   生成器真值范围与未来可可靠测得的范围分别说明。预览通过只说明模型/相机场景可以生成，
   不说明目标可辨识、算法定位成功、抗深度偏差或达到实机3–4 mm要求。

```bash
  --output experiments/neck_localization/runs/my_preparation_v2

```

新入口拒绝旧schema，避免静默改变尺寸含义。旧生成资产均保留，没有覆盖。

已生成`experiments/neck_localization/runs/preparation_20261022_v5/`，包括浅槽、平颈、局部歪颈、
较高较宽坛共4例。最初用于准备，后续已用于算法开发，不能作独立测试。
另准备4个留出场景；结果及边界见首轮报告。模型/场景检查13项，新增剖面回归4项，共17项通过：圆截面/尺寸、上下宽度关系、范围中点、闭合壁面/开口、
三角形朝向、歪颈过渡局部折叠检查、固定相机、真值隔离、RGB/浮点深度网格、独立网格射线深度核对。
闭合性与局部截面Jacobian检查不等于完成任意形变的全局自交证明。

每个案例包含：

- `scene.xml`与`assets/`：可直接加载的MJCF/OBJ/材质；静态，无设备接口。
- `observations/`：三台固定测量相机RGB、float32光轴Z米制深度、真值相机参数、显式诊断掩码。
- `evaluation_only/`：目标范围、圆心/法向/半径与剖面真值，不属于估计器输入。
- `review/overview.png`、`front.png`、`neck.png`：额外人审相机，仅检查形态，不用于定位。
- `manifest.json`、`model_manifest.json`：尺寸、相机画幅、局部折叠风险、环境版本与源码散列。

小预览和配置/清单快照见[模型准备记录](../../../experiments/neck_localization/results/short_neck_20261022/README.md)。
