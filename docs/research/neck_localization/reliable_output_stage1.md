# 提高正确输出率：连续支持、范围扩张与经验证的备用解

2026-10-23。用户明确本步核心是成功率，拒绝必须计失败；后续再考虑相机误差、5 mm扎带和跨工位机器人。
本报告记录两轮开发/冻结/独立测试，包括第一轮不利发现。没有操作实机或修改旧冻结算法。
后续约束另见[环带与坐标链契约](band_and_station_contract.md)。

## 1. 评价规则

正确输出=算法接受，且圆心≤4 mm、法向≤2°、直径≤2 mm；后两项仍是分析阈值。
错误输出、拒绝/无输出都计失败，不以接受候选为分母提高成绩。
真实工位时限尚未确定，因此报告耗时分布及1000 ms说明线；它不是产线SLA，未包括采集/传输。
本阶段准确仿真K/T、理想深度、固定人工三相机布局、同一圆截面模型家族。
两组随机范围沿用已声明假设，不是工厂测量分布或现场故障概率。

## 2. 原因与第一版改进

原36随机开发集的三视图区域法有两次失败：

- `nominal_002`：0.5 mm分箱核心下界在两位置切换，12轮未稳定；候选真值误差小。
- `stress_001`：长颈近最细范围触及28 mm候选域边界，同一帧的更宽点云尚未利用。

V1新增`reliable_output.py`，原`support_feedback.py`等冻结源码不改：

1. 用轴向Gaussian核局部半径均值代替硬分箱核心，中间网格仅为计算，不增加成像信息。
   核宽0.6 mm、核心半径增量0.3 mm、核心外权重渐变宽0.5 mm；不使用颈段真值。
2. 第一次区域更新后以0.5阻尼混合权重，最多24轮；保留0.005 mm/0.002°/权重0.015的停止条件。
3. 软件候选深度按28→42→56 mm尝试，同一帧重算，不重拍、不移动相机。
4. 初始候选确定后按索引留出25%点，75%参与轴/曲线；用核心、目标范围、留出残差和数据条件验证。
   初始口沿/ROI及支持检查仍用全观测，因此这是条件留出检查，不是独立相机/标定检验。
5. 必要时尝试固定权重备用轴，同样验证才可输出；缺深度不会因扩张/备用而强行成功。

训练核心至少60点+留出核心20点，对应旧80点数量要求；RMS 0.4 mm限未放宽。
完整读出继续保留上下文及两端支持，核心不充当作业范围端点。
所有相机信任系数为1。此阶段仍不是概率校准置信度。

开发36例三视图从34/36提高到36/36，无错误接受。
但预先锁定的第一批48个新案例（32常规+16压力，种子2026102337）显示：

|第一批新测试，三视图|正确输出|拒绝|错误接受|
|---|---:|---:|---:|
|旧区域法|47/48|1|0|
|V1连续区域/扩张/验证|46/48|2|0|

**V1没有取得独立测试上的成功率改善。**两次新失败为`stress_004`、`stress_008`，都是短且较陡的浅凹颈部，
内部核心宽度不足3 mm。旧法均有正确输出；V1把“内部拟合核心的最小跨度”误用为所有输出的必要条件。
第一批配置/冻结/全部432条新评价（48×三视图×三方法）及结果表保持不变，没有在其上改结果。
V1单/双视图仍有失败，其完整结果在`report/tables.md`，不能只报三视图开发成功。

## 3. 第二版：验证任务范围，不强制每种解都有宽核心

第一批48例在V2中明确降为开发集。实现前另锁种子2026102347的32常规+16压力48例，
V2仅评价当前三相机主工况；没有将一/二视图结果默认为同样可靠。
第二版`task_validated_output.py`复用V1，V1代码/第一次冻结文件均保持不变。

先运行V1。若已接受则几何不改；否则尝试以下备用提案：

- 用训练点的固定权重联合轴解；
- 用观测口沿给出的初始轴（不是GT，也不是硬约束所有坛颈必须平行口沿）。

每个提案都要在训练点上重新拟合完整半径曲线，获得**有两端支持的目标范围**，再检查：

- 功能目标区间至少1.5 mm（相当于三个0.5 mm支持区间），训练60点、留出20点、周向覆盖90°；
- 目标范围与其两端1.5 mm上下文的训练/留出径向RMS都≤0.4 mm；留出均值绝对值≤0.2 mm；
- 对有足够留出点的每台相机分别检查，防止相反偏差在总体均值中抵消；
- 仅用目标范围的数据Jacobian去掉样条干扰方向，检查轴信息条件；不让远肩或正则制造信息；
- 法向、尺寸、参数边界和优化收敛检查保留；两个合格备用提案中心差>2 mm或法向差>2°则不认作一致；
- 合格且一致时，按留出上下文RMS选择提案，不能按真值误差选结果。

这改变的是模型支持假设和验证区域，不是删除质量检查。
1.5 mm是当前理想观测工程支持要求，**不等于5 mm带可放入该区间**；未来环带任务须重新验收。
口沿提案的表现受当前生成模型“口沿与直颈方向一致”特性帮助，不能据此保证非平口沿/真实变形下有效。
备用提案必须由颈部数据验证，但仍不能检测共同标定偏差。

第二版开发48例三视图48/48；真正结论以另锁新48例为准，完整表位于`v2_report/tables.md`。
这套方法本质是多个提案加验证的工程组合，不把它直接称为新的科学方法或工业可靠性证明。
