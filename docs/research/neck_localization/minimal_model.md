# 首轮仿真前的最小几何与观测模型（草案）

更新：2026-10-22。状态：局部圆截面与范围中点规则已获用户认可；已准备静态场景并运行受限口沿方向代理基线，未实现独立的联合颈轴/剖面估计。
依据[工况与阶段约定](research_direction.md)及[视觉方案提案](visual_proposal.md)。
目的仅为明确未知量、观测、假设及退化情形，不在此完成所有可观测性证明或实机误差模型。

## 1. 范围与已知量

工位摆放按固定处理，每坛一次识别，背景清楚且无外物遮挡；各坛局部形状、颈位、颈向不同。
先建立静态几何测量模型，不建立机械臂动力学、传送带运动或完整包装工艺模型。
单次窗口的运动/曝光关系将来需核实，不把它当成已经完成的同步验收。

第一轮假定相机内参、畸变模型及米制外参已知且准确，RGB/深度坐标系及两者变换明确。
世界系W固定于工位，长度为米；相机系C采用+X右、+Y下、+Z前。
变换`T_C_from_W`将世界点送入相机：`p_C=R_CW p_W+t_CW`。
报告位置/尺寸误差换算毫米，方向误差为度。

这些是首轮诊断假设，不表示旧实机相机参数可复用或已独立验收。

## 2. 局部坛颈模型与未知量

只描述口唇下方到坛肩附近的局部曲面；为判断遮挡，可见性计算必须包含相邻口唇/肩部。
初始模型为可倾斜直轴、可变半径的旋转曲面：

\[
X(s,\theta)=a+s n+r(s)\{u\cos\theta+v\sin\theta\},
\quad \|n\|=1,\quad u\times v=n.
\]

每只坛独立估计轴线位置、方向及半径剖面`r(s)`。首版用有限维平滑曲线表示`r(s)`，
例如固定结点的样条；结点数/正则化尚待讨论，不让任意函数吸收所有观测误差。
方向`n`为局部颈轴，独立于坛身轴及口沿法向；采用`n·world_up>0`统一符号。
绕轴旋转不改变该模型，无需作为待估位姿。

**消除参数重复：**不规定轴向原点时，`a`沿轴移动且相应平移`r(s)`的自变量，会表示相同曲面。
令`a·n=0`，即`a`为轴线上距离世界原点最近的点，轴线有4个独立自由度；
若剖面有M个独立系数，初始几何未知量合计M+4，而非再加一个任意轴向原点。

局部直轴与近圆截面是待验证先验。局部倾斜在模型内；真正弯颈、明显不圆/不共面应作为
模型失配反例，不能用“适应歪颈”一并宣称已覆盖。

## 3. 从形状定义候选截面

在口唇下方明确的局部搜索域D内，暂以最细处定义几何候选：

\[
S^*=\operatorname*{argmin}_{s\in D}r(s).
\]

若`S*`只有一个内部位置`s*`，则目标候选参数为：

\[
c^*=a+s^* n,\qquad n^*=n,\qquad R^*=r(s^*).
\]

此处`n*=n`是直轴、圆截面模型的结果，不是所有真实酒坛的几何事实。
最细候选与实际扎带接触平面的关系、带宽及允许槽宽仍需工艺定义；不能把本草案的数学定义
写成用户已经确认的实物结构规则，也不能在全坛搜索全局最小半径。
用户后续接受先用圆截面，并提出最细候选不唯一时输出最细范围中间位置。因而当前生成模型采用：

```text
E = {s in D : r(s) <= min_D r + epsilon_r}
I = 与目标缩颈对应的单一连续分量 [s_lo, s_hi]
s_mid = (s_lo + s_hi) / 2
c_mid = a + s_mid n, R_mid = r(s_mid)
```

同时输出范围长度。`epsilon_r=1 mm`仅是当前生成器的显式半径容差假设，不是工艺标准。
平底模型中I为整个平颈段；浅槽I由解析函数定义，不取离散网格最小点。
不能跨多个分离极小区域求一个中点，也不能保证缺少观测时仍能可靠找到范围。
范围端点触及搜索域边界、多分量无法区分或形状不满足先验时仍需标记风险/拒绝。
范围中点定义不消除端点不确定性；它与单点极小值的扰动公式属于不同对象。

## 4. 相机到底观测什么

### RGB

\[
q_i=R_{C_iW}X+t_{C_iW},\qquad x_i=\pi(K_i,D_i,q_i).
\]

轮廓是可见曲面相对相机的视线切触包络，并不等于某一个截面圆的整圈投影。
若`e=u cos(theta)+v sin(theta)`，模型的外向单位法向为：

\[
N(s,\theta)=\frac{e-r'(s)n}{\sqrt{1+r'(s)^2}}.
\]

光滑表面的轮廓候选满足`N·(C_i-X)=0`，还须通过可见性/遮挡检查。
因此模型投影时要同时考虑轴向变化率与透视，不能把图像轮廓宽度简单换算成直径，
不能把不同相机的轮廓切点当作同名三维点直接三角化，不能用被口唇挡住的真值边缘当普通观测。

旋转曲面及轮廓的相关几何可参考[Wong、Mendonça、Cipolla原文](https://i.cs.hku.hk/~kykwong/publications/kykwong_ivc2004.pdf)。
上述局部模型与参数规范为本项目简化，尚未证明两视图足够或任意形状可由轮廓恢复。

### 深度

深度是各自深度相机的光轴Z，以米计算；RGB和深度的内外参分别处理，
不把对齐图自动视为没有遮挡/采样差异。参考[RealSense官方坐标与投影说明](https://github.com/realsenseai/librealsense/wiki/Projection-in-RealSense-SDK-2.0)。
初始分析用简化测量关系：

\[
z_i^{obs}=(1+\alpha_i)z_i^{surface}+\beta_i+\epsilon_i.
\]

`z_surface`是该像素射线首先遇到的可见表面Z；`alpha,beta`分别为每机固定尺度/偏置，
`epsilon`为随机项。它是可解释的分析模型，不是本机实际偏差规律的拟合结果。
第一轮准确测量诊断令三者为零；后续单独注入偏差，不在同一轮自由估计全部相机参数、
任意形状和任意深度偏差。尤其不能把XYZ独立加同方差噪声当作真实深度误差。

## 5. 首先需要的推导与待验证命题

**尺度歧义：**仅有一个RGB相机、未知物体尺寸时，将相机系物体坐标统一缩放为`lambda*q`
不改变针孔投影，不能仅由该图像恢复米制尺度。已知米制多机基线或可靠深度可增加约束，
但“两台相机就必然唯一”不是该结论的推论。

**最细处位置的敏感度：**若存在唯一内部极小值，`r'(s*)=0,r''(s*)>0`，
由扰动后的一阶极小值条件展开可得：

\[
\delta s^*\approx-\frac{\delta r'(s^*)}{r''(s^*)}.
\]

这是在固定轴、固定搜索域和光滑小扰动下的一阶关系。槽底曲率越小，最细位置越敏感；
半径误差小不代表轴向圆心误差小。完全平槽底不满足该展开的前提，应保留非唯一解，
不能除以接近零的曲率强行输出有限精度。

**局部与全局可辨识性：**后续对去除参数冗余后的观测残差计算数值Jacobian，
按参数单位/尺度归一化检查奇异值和敏感方向。要区分观测本身提供的信息与平滑先验；
正则化把矩阵变为可逆不证明数据可观测。局部满秩也不证明全局唯一，
还应检查不同初值、不同候选形状能否产生接近相同的可见观测。

深度偏差能否与真实坛形区分，属于后续逐项误差分析的问题；不能由这份理想模型推导出
RGB可以自动消除所有偏差。共同世界基准偏差等还可能需要外部独立参考。

## 6. 何时可以准备首个仿真

不需要等待完整论文证明。先讨论并确定本草案中的目标定义、局部圆/直轴假设、
参数规范、观测类型及多解输出规则，然后准备静态无噪声几何仿真即可。
仿真目的为检验这些假设与局部可观测性，不是直接完成最终精度报告。

首阶段建议只覆盖明显槽、平缓槽、局部倾斜颈，以及不圆/弯颈/口唇遮槽的反例；
固定摆放，准确相机，理想可见轮廓或明确标记的诊断掩码，原始浮点光轴深度。
精确目标参数仅生成器与评估器持有，估计器初值不能读取真值。
生成模型与估计模型相同时的成功只算实现诊断，失配反例应独立保留。

阶段结束要能解释：哪些情况可恢复，哪些有多个解释或对微小扰动敏感，哪些应拒绝；
不以提高分辨率或挑一个成功案例代替这一结论。通过后再讨论实际图像提取与有偏深度阶段。

**当前停点：**已明确局部圆截面和最细范围中点规则，已完成模型/静态场景和[受限首轮基线](short_neck_baseline.md)。
后续[优化分析](optimization_analysis.md)已推导局部轴/曲线残差雅可比并用有限差分核查，
给出简化圆弧证据的退化反例；尚未完成真实场景的任务可观测性评估，没有证明多视图全局唯一性，
没有开展传感器噪声实验或相机布局搜索。
本草案不构成跨阶段自动执行计划。
