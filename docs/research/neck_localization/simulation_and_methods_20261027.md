# 本轮仿真、三种方法与可视化回放说明

2026-10-27。对应[第一轮能力审查](capability_audit_20261027.md)。这是静态感知/定位仿真；本轮没有机器人运动、传送带运动或扎带接触闭环。新查看器只读保存数据，不重训网络或重算定位，也不调用设备。

**用户后续纠正：**原MuJoCo `view_structural_study.py --ground-truth`更直观，后续主展示应沿用原入口。本页新查看器作为已完成的辅助记录，不再作为主界面扩展；原入口当前尚未集成本轮模型结果。

## 仿真究竟生成了什么

1. `neck_localization/jar_model.py`生成参数化酒坛网格：圆截面坛身、肩部、口沿、短平颈/浅低谷颈，以及仅作用于局部口颈的倾斜和偏移。约600 mm坛高、125 mm口沿外径来自用户近似描述；其他不少尺寸、材质和轮廓为假设，不是实物扫描。每个案例的真实几何已知，但估计器没有拿到该坛的精确CAD。
2. 保存MuJoCo场景/工位模型；这轮主动双目RGB/IR观测实际由**SAPIEN**渲染。模型带斑驳灰色材质、深色内壁、蓝色背景。沿用D435预设的RGB与左右IR相机内外参，以及红外投影纹理。三套虚拟相机每次只开一个投影器，未建模真实多机IR串扰。
3. 固定12个已看坛型分别放在远、近两个预定布局，外加4个开发坛型。远布局名义相机距离0.8 m；近布局水平半径0.35 m、相机高度0.78 m，配置中的标称目标距离约0.394 m。每套传感器保存普通RGB和848×480左右IR。
4. SimSense从IR图匹配视差，得到原生左IR坐标系深度。FS比较中显式保存clean和shared_noise两套PNG，两个匹配器逐字节使用同一套图像，并关闭SimSense内部再次加噪；P2P/L-NDF则复用历史RGB-D。
5. 原生深度经相同1 mm Z16量化和离线librealsense注册到RGB，再反投影成世界坐标点云。离线SDK使用内存software_device，没有相机采集或设备发现。渲染器还独立保存理想深度和目标截面，用于控制与评分。

目标真值是“口沿下指定颈段中，半径不超过局部最小半径+1 mm的连续区间中点”。这是明确的合成任务定义，仍需现场独立测量确认是否代表实际最佳扎带区间。理想深度也不是部署输入。

实际D435i的陶瓷反射、噪声、标定偏差和多机干扰未由现场数据辨识。本轮是受控仿真证据，不能直接换成实物精度。

## 原本的几何方法在做什么

```text
IR左右图 → 传统匹配深度 → RGB前景/固定工位裁剪 → 世界点云
       → 口沿/平面候选初值 → 局部轴与半径曲线联合拟合
       → 读出近最细连续区间中点 → 截面圆心、法向、半径 → 验证/接受
```

给定候选局部轴，可以给每个点计算轴向坐标s和到轴的径向距离ρ；用平滑半径曲线r(s)描述局部曲面。求解器联合调整轴、曲线和支持权重，使ρ与r(s)符合，同时抑制离群点并限制支持范围。随后从曲线读出目标区间和截面。

审查保留两个冻结版本：`stereo_robust`是已有鲁棒几何读出；`portfolio`还包含多初值候选、RGB口沿圆锥曲线/深度平面、局部拟合及结构验证。当前所谓“原本方法”不是只做Hough圆检测，也没有拿真值轴去拟合。

两者的几何模型、初始化、目标函数和验证存在局限。特别portfolio中“任意目标截面的切点应贴整坛外轮廓”的关系已被证伪，还影响候选选择。这轮为归因保留它，因此候选几何达标与实际接受必须分开显示；修复后须重新运行，不能只删除拒绝字段。

## FoundationStereo：换掉深度计算前端

原理是**学习双目对应**。它组合细粒度CNN图像特征和冻结DepthAnythingV2的单目表征，通过side-tuning适配；构造左右图的匹配代价体，用卷积与视差Transformer聚合空间/视差上下文，再用GRU迭代细化视差。输出仍是左右像素对应形成的视差，不是直接回归坛颈圆。[官方方法说明](https://nvlabs.github.io/FoundationStereo/)

本项目实现：

- 官方ViT-large完整权重严格载入，不用酒坛数据训练或微调。
- 保存的灰度IR复制为3通道，保留848×480完整分辨率；网络所需补边在输出时去掉。没有把IR伪装成另一个RGB场景。
- 32次视差细化，得到d后按 **Z=fB/d** 换成米制深度；这里f约430.14 px、B约50.157 mm，使用IR参数。
- 之后的量化、RGB注册、点云提取、两个几何后端及门槛全部保持不变。

```text
相同IR → FoundationStereo视差 → 米制深度 → 原有几何定位
```

与原方法的差异发生在“IR算深度”。原SimSense使用Census等局部匹配代价、匹配块及平滑约束；学习网络使用预训练表征和更大范围上下文。网络并不知道当前图里哪一圈是扎带位置。

实现：`neck_localization/foundation_stereo_baseline.py`、`scripts/run_foundation_stereo_capability.py`。近距候选5/12→11/12来自这项前端替换；远距退化和错误接受也保留，未宣称全面更好。

## P2P-Bridge：修改点云，再做原有几何读出

原理是**学习点云恢复**。原论文通过配对的有噪/干净点集学习Diffusion Schrödinger bridge及传输过程，使测量点集向较干净的表面演化。它不是双目匹配器，也不直接输出功能截面。[官方实现与论文](https://github.com/matvogel/P2P-Bridge)

本项目实现：

- 历史普通RGB-D按相机K/T反投影，使用正式蓝幕前景及固定工位范围；保留观测上包络以下70 mm，三视合并并固定采8192点。
- 米制点归一化，按官方几何规则构成12个2048点邻域patch；使用官方XYZ权重、EMA和5步OT-ODE恢复。此处没有用RGB/DINO特征条件版本，RGB只参与前景提取。
- 恢复到米制后，重叠patch按来源点平均。外层适配采用逐来源点聚合而非官方object入口末端FPS重采样，这项差别已明确记录。
- 恢复云回投到每个点原来的相机，保留最近Z、同样1 mm量化、不补洞，再交原有几何读出。
- 相同裁剪/8192采样但不恢复的点云也执行同样回投，作为配对控制。

```text
已有RGB-D → 点云 → P2P恢复 → 回投深度 → 原有几何定位
                    对照：相同点云不恢复 ───────┘
```

区别是学习模型会移动三维点。它可能减小噪声，也可能改动浅低谷或短颈；回投还会改变空洞、碰撞和后端有效支持。当前结果只隔离到完整恢复适配流水线，尚未把这些机制逐一分开。v1旧亮度mask漏掉暗颈，已作为接口诊断保留；实际评价采用修正后的v2。

实现：`neck_localization/point_restoration_baseline.py`、`scripts/run_point_restoration_capability.py`。其历史raw不是FS本轮的共享IR条件，不能直接用两个通过率给网络排名。

## L-NDF：从示教迁移功能坐标系

原理是**局部神经描述符匹配**。网络根据观测点云P，给连续三维查询位置x返回局部描述符f(P,x)。在示教物体的任务坐标系里放一组查询点q，保存它们描述的局部形状；新物体上寻找刚体变换T，使f(P,Tq)与示教特征接近，由此迁移任务坐标系。[官方方法说明](https://elchun.github.io/lndf/)

本项目实现：

- 只输入cam_a单视RGB-D前景点云。
- 使用4个开发坛型的已知目标圆心/轴作监督示教。用这些标签构造功能帧，在帧内放1000个环形查询点并汇总示教描述符；不是零示教、也没有使用12个审查坛型标签。
- 官方预训练网络保持冻结；每个新物体优化的是功能帧T，而不是网络权重。采用官方bottle的cosine损失、20个初值、500步优化。
- 开发阶段比较全前景与上部70 mm两种配置，按预先协议选全前景后冻结；测试输出中心和轴，不预测半径。

```text
4个开发点云 + 示教功能帧 → 任务描述符
新物体点云 → 匹配任务描述符、优化T → 目标中心与轴
```

它直接替代了“通过曲线最细处找功能帧”这一环节；本轮未接后续圆/尺寸拟合。该方法属于少示教迁移加连续优化，不是强化学习，也未在酒坛上训练模仿策略。

当前适配在开发ideal上也未通过毫米级控制；query上下文、描述符平均、尺度归一化和域差异都有影响。固定模型空间query还原后的物理高度实际变化到约2.71–14.57 mm，不能称每坛固定3 mm带。这是当前适配失效，不能据0/48断言L-NDF类方法不可能解决任务。

实现：`neck_localization/lndf_baseline.py`、`scripts/run_lndf_capability.py`。

左侧可切11种方法/输入分支、远近布局、12坛型和两个几何后端；上下图可旋转。`←/→`或按钮换坛；点击“查看实际输入图像”打开保存的左右IR（双目组）或原始RGB（RGB-D组）。

- 灰色：保存的真实CAD参考表面，**只用于展示**，不是模型补全结果。
- 彩色点：输入前景点云；并不把它们全部冒充实际拟合支持点。P2P显示实际回投/量化后读出输入；L-NDF显示保存的cam_a模型输入。
- 绿色：仅评价用的目标截面，可隐藏。
- 橙色虚线：保存的几何候选圆，可能被拒绝；底部同时显示几何达标与实际接受。
- 紫色中心/轴：L-NDF输出，无预测半径，**不会绘制假的预测圆**。
- 右上为固定目标附近放大；下方RGB采用统一评价展示视窗。真值、CAD和展示裁剪不进入推理。
- RGB上的圆线是完整几何投影，未按实体遮挡裁掉背面弧；它不表示相机实际能看到整圈。
