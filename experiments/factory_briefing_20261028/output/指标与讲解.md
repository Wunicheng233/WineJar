# 酒厂汇报素材使用说明

准备日期：2026-10-28。图片为3840×2160，16:9，可整页插入PPT。配套PPT的文字和图表可编辑。所有画面来自现有MuJoCo场景或保存的仿真相机输入，没有用AI图片代替实验。

## 建议顺序

1. **三工位流程**：先拍照找准坛颈，再覆盖坛口，最后机械臂按记录的位置到达扎口工位。上料在这组仿真中只简化为不透明遮盖。
2. **定位效果**：红色圆环表示系统找到的扎带位置，箭头表示朝向。青色虚线是模型的真实位置，仅用于比较，算法看不到它。
3. **不同坛型**：验证不止一只标准坛子。图示6种，完整测试11种。02号保留了带宽不通过的失败结果。
4. **定位指标**：这一批模型上的定位误差已较小，但定位精度和能否真正扎好仍是两个验收项目。
5. **扎口动作**：展示到达上方、下降、合拢。尚未证明实际扎紧、锁紧、剪断和整机碰撞安全。
6. **相机输入**：可作备用页。有需要时解释“相机通过深度数据重建三维表面”，不用展开算法。

如果汇报时间较短，保留第1、2、4、5张即可。

统计对象是**本轮候选组合方案**`pose_fs_radius`，并非宣布替换部署默认方案。圆心/法向来自SimSense双目深度加旋转曲面拟合，半径来自已保存的FoundationStereo可见区估计。两路共享输入，不假设独立。未重新训练或运行学习模型来制作汇报图。

这11种模型已经用于工程优化，不能称为全新的独立盲测，更不能把此小样本结果解释为工厂成功率。现场绝对精度、传送到位误差、相机与机械臂标定、工具安装以及最终扎口效果，都需要实际验收。没有经过验证的生产节拍，不建议写“每只几秒”或“产能提高多少”。

## 一段可直接讲的话

> 目前我们已经把识别、遮盖和机械臂对位的流程放进仿真里验证。系统能同时找到扎带的位置和坛口的倾斜方向。在这批11种酒坛模型、两组输入条件的测试中，圆心最大误差约2.7毫米。不过真正扎好还需要考虑扎带宽度、传送到位误差和机械臂标定。目前每组有10种模型满足3毫米带宽的几何要求，剩余问题和实机扎口效果是下一步验证重点。
