# 标定与跨工位传递的科研线索

2026-10-29。仅供用户带回科研会话，未发送其他会话。依据[本轮工程实验](uncertain_transfer_20261029.md)，不宣称新颖性或成熟方法缺口。

**现象：**训练图重投影残差、不确定性手眼的条件协方差、机器人实际到位误差、有限带宽可用性是四件事。实际渲染部分角点中，留出像素RMS 0.503→0.140 px，但标定/执行新增误差P95只从1.268→1.014 mm，总圆心P95反而2.613→2.666 mm，整带均10/11。新种子中另有圆心3.017 mm但带越界0.102 mm的例子。

**已有方法：**TRO不确定性手眼、ISPRS最小运动学/图像联合标定、NIST局部校准，以及标准整图鲁棒估计已有直接相关证据。来源和本项目适配差异见工程报告。普通PoE＋Cauchy已大幅缓解模拟的结构偏差/整图异常，不能把这些方法的应用本身包装成贡献。单张坏图、参数方差欠覆盖也不是新发现。

补充简单对照同样保留：固定X/Y外参＋相同整图Cauchy在强结构/含坏图的新增误差P95为1.573/1.479 mm，关节映射为0.457/0.892 mm；只有图像噪声时简单模型反而更好。这是开封后补充对照，支持按误差机制选复杂度，不构成新的独立科研测试。

**尚待验证的问题：**上游局部几何偏差、共用基准固定偏差、机器人姿态相关偏差如何共同消耗窄带余量？一般任务空间误差传播与鲁棒放置能否已经满足实际要求？当前仅圆截面、假设误差及11已看坛，不足以证实真实问题或文献未解决。

**最小证伪实验：**先用独立实物基准测实际可用槽与工具落点，冻结标定/测试分组。相同图像、姿态覆盖及测量预算，对比简单外参、最小运动学联合标定、标准鲁棒版本；分别报独立参考误差、带几何和接触结果。将固定公共偏差与逐周期变化保留分层，考察预测区间覆盖。若标准标定＋普通误差传播/余量规划足以达标，应撤下方法缺口假设。若只在模型外的负载/热漂/反光或非圆槽上失败，先确定该失效是否有成熟针对方法，再设计最小新实验；不靠增加非必要挑战维持研究题。

本轮没有现场测量、训练、最终扎紧或跨工位公共基准的完整独立验收，不能据仿真成功率推断工业可靠性。
