# 标定与跨工位位姿传递：本轮工程结果

2026-10-29。全部为离线仿真，未连接设备、采集、训练、改现场标定或更换默认定位流程。

**本轮解决了一类问题：机器人自身存在连杆/关节偏差时，仅求一个“相机到机器人”的刚体变换不够。用相机图像校正关节到工具的映射，能明显减少这部分到位误差；再对整张异常标定图加权，可以避免一个坏观测拖偏结果。实际渲染图像也验证了收益，但提升较小，3 mm整带仍有失败，不能宣布可部署或扎口成功。**

正式结果根目录：`experiments/neck_localization/results/uncertain_transfer_20261029_v1/`，下文路径均相对该目录。原定位输入、点云、算法和三工位默认流程不改。

## 1. 这次具体增加了什么

| 增加的工作 | 为什么需要 | 实际实现与取舍 |
|---|---|---|
| 带结构偏差的机器人模型 | 原试验把控制器报告的笛卡尔位姿当成准确到位 | 复制MuJoCo模型，扰动连杆坐标、关节零位/尺度；求指令关节后，用扰动模型重新算实际枪头。幅度是假设，不是xArm实测性能 |
| 不确定性手眼标定对照 | 检验成熟方法能否直接解决 | 按TRO论文的虚拟观测/方差分量思想适配；对独立位姿随机误差有用，未解决本轮结构偏差和整图异常，不设默认 |
| 相机参考的关节映射 | 一个固定外参不能补偿随关节姿态变化的误差 | 标定30个轴线/初始板位姿参数，直接预测给定编码器读数时，板在相机中的位姿；不是分别声称识别出真实DH、基座和TCP |
| 整图鲁棒权重 | 同一图的全部角点可能一起偏移 | 在同一关节映射上增加标准Cauchy整图IRLS对照，不向算法提供坏图编号或真值 |
| 部分ChArUco角点输入 | 实际渲染图没有任何一帧检出全部35角点 | 按ID使用实际检出的角点，缺角不填真值；30图保留18图，12标定、6留出。排除12图计入采样可用性限制 |
| 受限的坛身位置修正 | 下游二次视觉可能比小幅停位误差更差 | 对已有输入比较直接修正、区间修正和不修正。区间宽度未知，暂不把二次视觉加到默认流程 |

这些是**候选方案及消融对照**，不是把全部方法依次叠加。标定是离线工作，不是每只酒坛重新标定，也未新增网络训练。

## 2. 标定机理及坐标链

统一用米、弧度；`A_T_B`把B坐标转换到A坐标。W为共用场地坐标，B为机器人基座，C为扎口工位的标定相机，F为法兰，P为刚性标定板，G为150 mm内圆中心及轴。圆环法向向上，比较有向夹角；圆本身不约束绕法向旋转，仍沿用固定偏好方向确定枪头朝向。

原方法在多组图像中联合求`X=B_T_C`与`Y=F_T_P`：

`predicted_pixel = project(K, inverse(X) · B_T_F_reported(q) · Y · board_point)`

问题是`B_T_F_reported`来自名义运动学。如果连杆或关节零位有误，相机可能把机器人误差吸收到X/Y中。一个刚体外参无法对所有姿态同时消除这种变化。

本轮关节映射直接拟合：

`C_T_P(q; θ) = exp(S1 q1) · … · exp(S6 q6) · C_T_P(0)`

每根转轴用2个方向参数、2个横向位置参数表示，加6个初始板位姿参数，共30个。用相同编码器读数、已知板角点和图像像素优化重投影，并对轴线相对名义值加弱正则。关节尺度仍固定为名义值；并没有使用模拟器注入的真实偏差。

整图加权版在初值后重复求权重与加权最小二乘，至多6轮：

`w_j = 1 / (1 + mean((pixel_residual_j / 0.15 px)^2) / 4)`

这里j是一张标定图，权重同时作用于这张图中所有角点。0.15 px和Cauchy尺度是预设试验参数，不是实测相机精度。逐角点Huber与整图加权两种误差假设都保留比较；部分角点适配的初值使用soft-L1，不能称逐字复现原论文。源码：`neck_localization/poe_camera_calibration.py`、`partial_board_calibration.py`。

执行时，上游定位得到的圆心/法向先按名义输送量变到扎口工位，再构造目标枪头位姿`C_T_G_desired`。独立夹具计量提供`P_T_G_measured`，据此求：

`C_T_P_desired = C_T_G_desired · inverse(P_T_G_measured)`

然后在关节限位内解`C_T_P(q; θ) = C_T_P_desired`，获得候选关节指令。评估器用另一份真实偏差模型和真实安装关系计算实际枪头位姿；估计器不能读取它们。**现阶段只是离线逆解，没有向控制器发送关节命令。**

这并未取消跨工位统一基准：上游W到下游C的变换仍必须独立标定，输送净位移仍必须验证。本轮关节映射主比较将这段变换与名义输送量视为准确，以隔离机器人标定问题；此前的工位/停位误差试验及本轮坛身修正另行报告，不能把它们拼成已验证的全链精度。

标定时相机只需看机器人上的板，运行时不用重新看到被遮盖的坛颈。仿真标定场景卸下了枪头、装上板；实物夹具、板与枪头的共同基准及重装重复性尚未设计/测量。新工具安装假设不能复用旧吸盘116 mm TCP。

## 3. 方法依据及适用边界

- [Ulrich & Hillemann：Uncertainty-Aware Hand–Eye Calibration，TRO，2023接收稿](https://publikationen.bibliothek.kit.edu/1000167305/152029292)：阅读了虚拟机器人位姿观测、方差分量及结构误差实验部分。本项目实现其相关思想，固定K、使用旋转向量局部坐标，不是HALCON或论文全部功能的复现。训练姿态的修正量不能自动推广成新的机器人运动学模型。
- [Ulrich等：Vision-guided robot calibration using photogrammetric methods，ISPRS，2024](https://publikationen.bibliothek.kit.edu/1000174827/154979691)：联合图像与机器人模型标定、最小参数化和接近平行轴时的参数稳定性，与本问题直接相关。本文使用DHHM，本项目用标准PoE轴线适配，不宣称新算法或完整复现；未联合优化相机内参。
- [NIST：Using Locally Adjustable Hand-Eye Calibrations to Reduce Robot Localization Error，2020](https://www.nist.gov/publications/using-locally-adjustable-hand-eye-calibrations-reduce-robot-localization-error)：支持关注作业区域中随位置变化的误差，并在目标区域独立验证。本轮没有实现该论文的局部插值法，也不以其文献成绩代替本项目结果。

**项目推断：**若现场主要是结构性运动学误差，应优先检查关节映射/作业区校正；若误差很小，简单外参可能更合适。当前证据只支持所模拟的偏差类型。背隙、载荷挠曲、温漂、关节重复性和动态跟踪未被该模型覆盖。现有模拟误差大部分可被PoE表示，因而本轮是机制验证，不能外推任意真实机器人。

原文PDF、提取文本及散列在`experiments/neck_localization/runs/uncertain_transfer_sources_20261029_v1/`。未找到/未运行作者官方软件的部分没有冒充官方结果。

## 4. 冻结后新标定批次的对照

开发用2个模拟标定批次；冻结5个候选源/配置文件后，另用4个种子`2026102981/83/87/91`。每批18姿态标定、12姿态留出；7×5板角点、20 mm间距。每条件每方法在11只**此前已看过的酒坛**上评价，共44落点。是新偏差/采样批次，不是新坛型、实机或44次独立工厂试验。

所有方法使用同一图像/编码器/板及独立工具夹具测量。基线把编码器转换成名义法兰位姿，关节映射直接使用编码器；后者的额外自由度和模型假设是方案差异。首轮独立笛卡尔位姿随机误差对照另存，未把编码器提供额外准确运动信息的情况混入此表。

偏差幅度：角点σ0.15 px；每连杆平移σ0.05 mm、局部转角和关节零位σ0.02°、关节尺度σ0.0001，结构强档统一乘5。整图异常为一张训练图全部角点偏[+4,−3] px。错误K为fx+0.2%，同时有弱档结构偏差。工具实际安装σ0.6 mm/0.15°，独立夹具测量σ0.1 mm/0.03°。固定偏差一批内不变，不是逐点独立高斯扰动；这些幅度全部是假设扫描，尚无现场辨识。

下表是**标定、工具计量及执行新增加的圆心误差P95，mm**，相对于同一上游视觉目标；不是总定位误差：

| 条件 | 原像素Huber | 不确定性标定 | 关节映射 | 关节映射＋整图权重 |
|---|---:|---:|---:|---:|
| 无图像/运动学误差，仅工具计量残差 | 0.264 | 0.264 | 0.264 | 0.264 |
| 仅图像随机误差 | 0.284 | 0.281 | 0.341 | 0.379 |
| 弱结构偏差 | 0.459 | 0.353 | 0.353 | 0.390 |
| 强结构偏差 | 1.698 | 2.244 | 0.418 | 0.457 |
| 强结构偏差＋一张坏图 | 2.129 | 3.913 | 4.157 | 0.892 |

解释：增加自由度本身有风险。普通关节映射在坏图下比原方法更差；整图鲁棒权重在该条件有明确作用。在只有图像噪声时，新法反而略差，不能无条件替换简单方法。不同模块不是每种条件下都应该启用。

## 5. 实际渲染RGB：收益更小，也有回退

前表用投影后扰动的角点检验几何机制，不能冒充经过成像/角点检测。另生成30张640×480 MuJoCo RGB图，使用实际ChArUco检测、ID和亚像素细化，不叠加角点高斯噪声、不把漏检角点补成真值。

全角点适配器首次0张完整，负结果留在`rendered_board/detection.json`；改为部分ID输入后18张可用、12张排除，12张标定/6张留出。图像可用率18/30不是酒坛识别成功率。此项是看过渲染可用性后做的接口适配，只有同批次留出，尚无第二批独立实际图像验证。

| 指标 | 原像素Huber | 映射＋整图权重 |
|---|---:|---:|
| 留出图像重投影RMS，px | 0.503 | 0.140 |
| 标定/执行新增误差P95，mm | 1.268 | 1.014 |
| 总圆心误差P95，mm | 2.613 | 2.666 |
| 总圆心误差最大，mm | 2.762 | 2.710 |
| 3 mm带包含 | 10/11 | 10/11 |

因此“像素残差降得多”不等于“最终任务误差降得多”。标定误差向量与既有视觉误差相加，抵消关系变化可使总P95稍差。不能只拿前表0.457 mm宣称成像后的能力。实际角点采样误差中位0.082 px/P95 0.241 px；导出XML取整引起的真值投影差最大0.000892 px，已另审计，远小于检测误差。

此RGB仍是理想内参、简化光照/印刷板、静态机器人。仿真模型与估计模型接近，不能作为真实相机/真实标定板可靠性的证明。

## 6. 不确定性和跨工位二次确认的负结果

不确定性标定会输出条件协方差，但它只含所设随机项及工具计量项。首轮6新模拟批次中，95%椭球对独立机器人位姿噪声的覆盖约98.5%，强结构偏差仅25.8%、结构＋坏图31.8%；错误K条件更低。**这些区间漏掉了结构执行偏差及上游误差，不能作为整个扎口链的置信度。**这不是证明原论文无效，而是说明当前适配/预算不完整。关节映射尚未输出经覆盖检验的不确定性。

下游坛身确认使用10-28冻结的SimSense输入，不重新看被遮住的颈部，也没有重新生成有利点云。仅修正输送方向一个自由度，比较4法：不修正、全量视觉修正、区间交集、零均值假设下的收缩估计。区间法为：

`真实停位误差 ∈ [-a,a] ∩ [视觉测量-b, 视觉测量+b]`

取交集中心；交集空或观测缺失则维持名义位置并记异常，**不是允许执行或把酒坛丢弃**。a/b必须将来独立测量，不能从残差自动认定。

对假设停位界±0.5 mm、视觉误差界3 mm，在两固定停位×11坛的22条子集：

| 条件 | 直接视觉修正：输送误差P95，mm | 不修正/区间法，mm |
|---|---:|---:|
| 理想深度 | 0.318 | 0.500 |
| 下游深度固定偏3 mm | 2.625 | 0.500 |
| 局部外参偏1 mm | 0.981 | 0.500 |

深度偏3 mm时总圆心P95为3.842 vs 2.661 mm。该宽视觉界下区间法基本不更新，也没有改善20/22整带比例；其意义是检验不增加伤害的条件，而非声称视觉融合带来精度收益。完整扫描a=0.5/2 mm、b=0.5/1/3/5 mm，共9856条记录，含超出先验界的反例；同一个界用于所有条件，不按已知真值选界。当前不新增默认下游相机或该融合模块。

## 8. 下一步及现场验收准备

优先补完整链中的独立参考与误差预算，不再靠已看酒坛的通过率选标定。先保持原定位输入和两种标定候选冻结：

1. **统一基准和工具计量方案。**制定上游相机系到扎口工位相机/机器人系的共同基准测量；可用经过计量的刚性基准件/托盘，而不能仅用定时运行秒数当距离标尺。板尺寸/平面度、板到枪头内圆中心/轴、重装重复性需要独立计量。先制作离线采样清单和留出点，现场采集需另获授权。
2. **测实际误差，再选模型。**固定枪头负载/姿态，在完整作业区域采标定样本，并用不参与拟合的参考点/姿态测实际枪头；区分重复性、固定FK偏差、温漂、相机/板误差。不把标定RMS当验收。若简单外参已满足预算，不启用高自由度模型；反之对照本轮关节映射。
3. **跨工位试验。**按多次停位、不同坛/负载记录净到位误差，先确认“姿态不变”及沿带小误差假设。无证据前不默认加入3D坛身配准。联合误差试验必须保留共享基准误差相关性，不能把相机、机器人、输送独立高斯相加后当现场预测。
4. **把改正后的整条运动路径接入检查。**当前新映射仅验静态到位。下一离线闭环应覆盖上方进入、法向下降、张合全过程的修正关节连续性和完整枪头扫掠，再考虑全臂/盖料碰撞；最后才可能评估接触、张力、锁紧和剪断。

6 mm槽与3 mm带每侧仅1.5 mm理想轴向余量。约60 mm半径时1°方向误差会占约1.05 mm边缘余量；0.1°基准转角在0.5 m杠杆臂上可带来约0.87 mm位置偏差。位置最大4 mm仍保留为历史指标，但它不足以保证整带包含；工艺验收必须另报带边界、工具净空及最终扎紧质量。当前真实工艺可用性、实机绝对精度、全链置信度和最终扎口结果均**未验证**。
